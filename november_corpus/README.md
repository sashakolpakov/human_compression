# November corpus

[Human Compression](../README.md) · [October corpus](../october_corpus/README.md)

This directory is reserved for a second research corpus. Its researcher,
bibliography and source editions have not yet been registered. It currently
contains no manuscripts, reviewed results or compression measurements.

The existing work on finite groups, polytopes and incidence geometry is in
the [October corpus](../october_corpus/README.md).

The corpus will have its own source register, common theories, application
papers, attribution records and reproduction instructions. Comparisons will
use the [project's measurement principles](../README.md#what-compression-means)
and state which historical results each application recovers.
