Fixed-root active fallback method accepted
==========================================

The complete new source, exact difference, imported parser and both
propagators, and the two-page proof have been read independently. The
active residual store remains a subset of the complete historical store.
Thus an active unit contradiction is valid historically, and the fallback
retains exactly the historical admission predicate. The fixed original
unit assignment is separate and never updated by candidate queries.

Residual collisions in deletions do not imitate original producer
occurrences: they may remove one matching learned residual only. This
can force fallback but cannot create a false contradiction. Original
active clauses remain permanent. All records are parsed, including after
a contradiction, and an explicitly empty original addition is required.

Fresh compilation passed 339 oracle cases with exact first-invalid
addition comparisons, ten malformed cases and nine exact residual-counter
fixtures. Four new satisfiable collision cases independently reject the
precise invalid addition. The binary happens to be byte-identical to the
author binary; the compilation and tests were independent. Both native
proof pages were directly viewed.

Root supplied the combination and finite authored it; the earlier
fixed-unit design is attributed to root and l070. This is a distinct method
review, not a new theorem priority claim. No production proof was opened,
no graph excluded, and no source or branch status was changed. A concrete
production request still requires its own reviewed input and limits.
