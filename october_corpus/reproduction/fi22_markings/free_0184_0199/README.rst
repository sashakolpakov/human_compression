Sixteen additional Fi22 marking certificates
============================================

This package contains accepted original free indices 184 through 199. Twelve
have supplied 11- and 13-cycle witnesses for generation. Indices 194, 196, 197
and 199 have nonempty proper invariant point sets proving nongeneration.
The earlier 160..183 package and 47/90 archive are retained unchanged.

The verifier is a distinct fixed-scope edition of ../verify.py. Every
mathematical function, predicate and resource limit is unchanged. Its fixed
index, schema, row set and offset are 184..199; two shared-object path literals
adjust for this nested directory. The original degree-3510 operands, complete
28908-row witness bank and maximal-order table reuse three existing objects.

From the repository root::

    python3 -E -B -S october_corpus/reproduction/fi22_markings/free_0184_0199/verify.py --controls
    python3 -E -B -S october_corpus/reproduction/fi22_markings/free_0184_0199/verify.py --index 184

Run one index per invocation, without -O. Standard Python 3.9 or later on Linux
or macOS suffices. All 25 generic controls and 16 case replays passed for this
edition. REPLAY.json contains their genuine execution records. The guarded
checks took 2.230 seconds in total; their largest sampled process tree was
34,127,872 bytes. Earlier cases were not rerun.

The definitions, attribution and imported premises remain in ../IMPORTS.rst,
../generation_theorem.rst and ../intersection_theorem.tex. They include the
named simple Fi22 and full ambient automorphism group with outer order two;
normal index-two membership, the faithful original model and action; exact
Reader/member/class/word interpretation; block 2, class 13, endpoint 18 and
local class 164; the two-fibre and H=B premises; and the complete borrowed
simple-Fi22 maximal cover with its correction. Every supplied cycle edge,
including its final return, or every ab/bc image of every supplied set point
is checked. Generation remains separate from the existing rank-three
simplicity theorem for the same twelve triples. The point kernel gets no IP
credit.

The accepted local bank has 77 generation cases, 77 separately justified IPs
for those same cases, 100 nongeneration cases and 28,731 unpaid rows. The full
domain still has 105 selectors: 41 have zero contribution proved and 64 remain
globally unclosed. This package completes neither bank nor manuscript and
adds no conjecture, Lean or compression measurement credit.

Each invocation keeps 128 MiB and 140 seconds, 10,000,000 shared work units
with a 20-second work window, 8 MiB of physical reads, 32 paths, a 50,000-byte
Source limit, 2 MiB per input and 128 KiB of stdout. Every input is rehashed at
the end. The outer supervisor remains at 128 MiB and 150 seconds. Runtime and
memory observations, including the explicit admission profile used for the
last eleven cases, are recorded in REPLAY.json. That profile retains a 3 GiB
RAM floor and reserves the full 128 MiB process cap plus a further 512 MiB.
The original search profiles are unchanged.
