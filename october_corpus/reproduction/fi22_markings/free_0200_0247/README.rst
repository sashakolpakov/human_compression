Forty-eight additional Fi22 marking certificates
===============================================

This additive package covers original free indices 200 through 247 in the
existing Fi22 bank. The three canonical accepted epochs contain 36 generation
certificates and 12 nongeneration certificates. The same 36 generating triples
have a separate application of the retained rank-three intersection theorem.
The permutation checker itself proves no intersection theorem.

The verifier extends ../free_0184_0199/verify.py to this case range. Only
the index/schema/record-offset literals and descriptive counts change. Every
mathematical function, input check, resource bound and all 25 generic controls
are identical. The original operands, 28908-row witness bank and maximal-order
table reuse existing immutable public proof objects; no dataset is duplicated.

After installation, from the repository root::

    python3 -E -B -S october_corpus/reproduction/fi22_markings/free_0200_0247/verify.py --controls
    python3 -E -B -S october_corpus/reproduction/fi22_markings/free_0200_0247/verify.py --index 200

Run one original index per invocation, without -O. Python 3.9 or later and the
standard library on Linux or macOS suffice. All 25 controls and all 48 case
replays passed for this edition. VALIDATION.json identifies their exact inputs
and records the outcomes and measurements. No previous execution verdict was
transferred.

Generation checks every supplied edge, including the last return, of both
11- and 13-cycles in the original rotations ab and bc. Nongeneration checks
every ab and bc image of every point of a supplied nonempty proper set. The
exact original owner and 16-byte witness-row digest are checked for each index.
No search, SGS, private file, prior API response or permission gate is needed.

Read ../IMPORTS.rst, ../generation_theorem.rst and ../intersection_theorem.tex
for the self-contained arguments and attribution. The named simple Fi22,
full ambient automorphism group with Out2, original faithful model, normal
index-two membership, original Reader/member/class/word interpretations,
two-fibre transport and H=B are explicit imports. The complete borrowed
simple-Fi22 maximal cover is not replaced by an Aut(Fi22) table. The public
intersection theorem is byte-identical to the theorem adopted separately for
these same 36 triples. PROVENANCE.json records the mathematical epoch/row/hash
joins; internal SDK and operational archives are retained separately.

These cases fill the public gap after the 77 generation and 100 nongeneration
certificates through index 199. The corresponding accepted local bank has
113 generation cases,113 separate intersection proofs,112 nongeneration
cases and 28683 unpaid rows. The complete domain still has 105 selectors,
41 zero contributions and 64 globally unclosed selectors. This package closes
neither the bank nor the original manuscript and adds no conjecture, Lean or
compression measurement credit.

The existing bounds remain 128 MiB/140 seconds per process, 10,000,000 shared
work units with a 20-second window, 8 MiB of cumulative worker reads, 32 paths,
50,000 Source bytes, 2 MiB per input and 128KiB of stdout. Every opened input is
rehashed at the end. Root's outer replay supervisor remains 128 MiB/150 seconds
with its original admission and floors. The largest observed case used
1,204,521 input bytes and 2,719,781 work units. The largest sampled resident
memory total was 28,737,536 bytes; every guard invocation finished within
0.389 seconds. These figures describe the observed runs.
