Finite matrix certificates for 285 original quartets
====================================================

This directory verifies 12 failures of the intersection property and 273
nongeneration certificates in the acquired natural matrix model of G2(11).
All 285 concern original job 24. From the repository root run::

    python3 -E -B -S october_corpus/reproduction/matrix_certificates/verify.py

Python 3.9 or later and its standard library suffice. Do not use -O.
The verifier writes no files. It reads five supplied JSON files, checks
their complete SHA256 identities, and reconstructs the original matrices.

The first guarded execution passed all 285 certificates. It used 8,521
matrix products and charged 652,776 bytes of data reads. See REPLAY.json
for the observed result, code identity and execution limits.

What the proofs establish
-------------------------

For each of the 12 intersection obstructions, the verifier evaluates a
word in one end subgroup, checks an element of exact order 37, computes
its fixed line, and checks that a generator of the same end moves it.
With the imported maximal subgroup classification, this proves that the
end is the whole group. Its intersection with the subgroup generated by
the omitted nonidentity mark then violates the intersection property.

For each of the 273 nongeneration cases, all four original marks preserve
a displayed line, while a known ambient group element moves that line.
The subgroup generated by the four marks is therefore proper. This
argument requires no maximal subgroup classification.

THEORY.rst gives the arguments, references and borrowed premises. The
verifier checks the original position and representative index, the
accepted matrix hash, four distinct nonidentity involutions, all distant
commutation relations, and the displayed equations.

Scope and attribution
---------------------

The original named group, membership, faithful frame and orbit transport
remain imported. This replay does not repeat the original point-action
bridge or identify the group from scratch. Absolute paths in the original
JSON files are provenance only; the verifier opens no such paths.

SOURCE_PROVENANCE.json identifies the earlier arithmetic code and the
accepted certificates. The stabilizer arguments are standard. The
residual assertion about absence of a rational common line is not
replayed here.

These 285 cases are additional to the earlier archive of 1,089
intersection obstructions. Neither collection completes the census or
the positive classification. This release adds no whole manuscript,
open conjecture, Lean or compression measurement credit.
