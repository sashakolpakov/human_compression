\begin{proposition}
The simultaneous transporter in \texttt{fusion\_conjugation.g} decides
equivalence of ordered subgroup families under conjugation by $N$ and
arbitrary permutations of their types. Every positive answer contains a
literal permutation of the 100 points and a type permutation.
\end{proposition}
\begin{proof}
Fix a type permutation, so that the desired target family is
$(Q_1,\ldots,Q_r)$. Begin with the original family $(P_1,\ldots,P_r)$,
accumulated conjugator $a=1$, and acting group $C=N$. At step $i$, find
$x\in C$ carrying the current $i$th subgroup to $Q_i$; if none exists,
this type permutation is impossible. Conjugate every current subgroup
by $x$, replace $a$ by $ax$, and replace $C$ by $N_C(Q_i)$.
The earlier target subgroups remain fixed. Inductively, every possible
completion differs from this chosen partial transporter by an element
of the new $C$: if two elements carry the same subgroup to $Q_i$,
their quotient on the target side normalizes $Q_i$.
Thus a failed step excludes every completion for this type permutation,
and success carries the entire family. Trying every type permutation
is exhaustive. Orders of individual groups, pair intersections and the
full intersection are used only as necessary rejection tests.
The code checks $a\in N$ and $P_i^a=Q_i$ literally before returning.
\end{proof}
