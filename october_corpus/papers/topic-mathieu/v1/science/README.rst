Primitive Mathieu geometries: complete corrected L073 candidate
=============================================================

This is a private author candidate for the complete nine-page 2010 original
L073, not an admission or a new result-priority claim. It reuses the previously
reviewed phase164/173 census and the author-only phase180 source-coordinate
work. The present author was the phase173 independent reviewer. This new
edition requires a different independent mathematical review.

Read ``primitive-mathieu-geometries.pdf`` (6 pages), then the complete
``class-tables.pdf`` (10), ``source-rows.pdf`` (9), and
``required-programs.pdf`` (11). All pages, including references and table
continuations, belong to the declared packet. No measurement or ratio is
provided. All seven mathematical programs are required and printed in full;
the three auxiliary scripts and source-coordinate/witness data are separate.

The proof gives the exhaustive 81 pair classes and 431 triple classes under
group-automorphism and arbitrary-type equivalence. It proves the actual
coset realization, residual-connectivity and chamber-completion criteria,
and complete orbit augmentation. It supplies a fresh separating table and
every literal permutation witness. TomLib catalogue completeness, the named
Mathieu model, exact GAP/SmallGroups/Design/GRAPE algorithms and the stated
classical Steiner/Golay/Atlas identifications remain retained premises.
There is no Lean declaration and no hidden old umbrella manuscript premise.
The special L095 universal-group theorem is not used.

Every one of the 431 physical source rows has a separate disposition. This
does not reconstruct the unavailable intended ``geo[]`` numbering or assert
that inconsistent labels all describe the printed objects. The main source
permits endecad complements independently. Consequently the canonical-only
predecessor convention is a separate diagnostic, and three rows formerly
rejected under that restriction now have compatible witnesses. The source
predecessor's pair-order table and literal pair definitions are also kept
separate; invalid objects are null and the undefined ``e4`` interpretation
is explicitly provisional. For printed juxtaposed Borel extensions only a
normal elementary abelian kernel and named quotient are inferred, while the
new class table supplies exact SmallGroups identifiers.

Reproduction
------------

Use Python with pypdf, GAP 4.15.1 and the exact retained package versions/data
listed in ``computational_inputs.json``. The output directory must not exist::

  python3 -B -O check.py --out /fresh/output --gap /path/to/gap

To rebuild all four documents and check page-text equality and whole-file
code inclusion, add::

  --render --xelatex /path/to/xelatex

The renderer requires STIXGeneral, STIX Two Math and Menlo. A private primary
and historical-binding audit is optional::

  --study-root /path/to/research/leemans

The export-only replay needs no primary PDF, old Markdown manuscript or
historical geometry download. Every mathematical stage runs afresh, with
a 90-second per-child bound and cancellation limited to that child process
group. The runner preserves exact stdout/stderr, including the inherited
GAP syntactic forward-reference warnings. It rejects actual errors, missing
stage sentinels, incomplete source rows, changed inputs, missing classes,
false signature separation and changes in the reconciled full tables.

The 15 controls include two actual finite countermodels: all local residue
generation equations hold but chamber transitivity fails. Such sample
checks do not prove the universal reduction; its proof is in the main paper.
Likewise post-enumeration validation does not by itself establish exhaustion.

``source_bindings.json`` binds the complete target and the predecessor;
``reading/source_reading.json`` explicitly distinguishes all nine target
pages from the targeted predecessor pages. Primary PDFs and page images
are private retained sources and are not exported. The source ledger has
14 main clauses plus all 431 physical table rows. ``proof_map.json`` binds
seven complete named statements/proofs. The final manifest binds every
export and does not include itself, caches or generated TeX build products.
