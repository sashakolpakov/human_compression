Coset intersections and the complete N005 application
===================================================

This is a private integrated edition built from distinctly reviewed proof
packets.  Its source is exactly Piedade--Tranchida, arXiv:2505.24662v1.
The complete frozen adapters and every prior review remain unchanged.
The new editorial migration itself requires independent review.

``common-theory.tex`` is a complete common paper.  It gives the coset and
residue calculus once, then separately proves tree gluing, coherent
amalgamation, free-product panels, compatible HNN transfer, indexed and
active-type reductions, semidirect joins, orbit twisting, cyclic markings,
exact presentations, and the full existing signed-module theory.  It does
not assert an all-graphs transfer theorem.

``application.tex`` is the complete N005 application.  It keeps the full
literal examples, all new uniform arguments, source corrections, retained
classical interfaces, and required small affine certificate.  The 81-row
``source_migration.json`` preserves the exact source dispositions.  The
counterexamples to false source formulas do not imply false conclusions
for the valid coherent, firm, or residually connected branches.  General
fundamental-geometry and categorical questions are not answered here.

``programs.tex`` prints all three whole local mathematical programs.
Only ``affine_example.py`` is a finite proof premise, for s = 2, 3, 4.
The presentation and literal-twist programs are validation.  The original
four mathematical countermodels are preserved in ``controls.py``.
Operational checking is separate.  There is no new Lean theorem.

The new common paper includes every required own mathematical proof;
older proof-bank manuscripts are provenance, not unpriced premises.
Its signed-module section serves N006 and is unused by N005.  For a future
three-original volume, N006's complete application, both sporadic
companions, all 18 GAP files and both data-decoding drivers remain paid;
N007's complete application and validation file remain paid.  Exact
unchanged sibling bindings and roles are in ``sibling_interfaces.json``.
The external named-group data and classification inputs are not reduced
to the sizes of the compact word certificates.  No numerical factor is
computed here.  Other topics must still pay their full own umbrellas.

Portable replay
---------------

With Python providing pypdf and SymPy, run from a copied packet::

  python3 -B -O check.py --out /fresh/absolute/output --programs --render \
      --xelatex /path/to/xelatex \
      --source /path/to/2505.24662v1.pdf

The primary flag is optional and checks the exact existing source hash.
The packet contains no primary PDF, text or raster.  The checker verifies
all source dispositions, program roles, retained interfaces, local theorem
references and five false-scope mutations.  The optional program run
replays the complete small certificate, both validations and four original
controls.  Fresh rendering covers both papers and the whole code appendix,
with exact per-page extracted-text comparison.  It writes only to the
fresh output directory; all frozen inputs are read-only.

``migration_segments.json`` gives the old line spans and destinations;
``dependency_inventory.json`` gives all 17 whole scientific source texts
and their accepted review provenance.  ``current_spans.json`` binds every
current label and proof section.  These are overlapping proof locators,
not a cost partition or a logical-node measurement.
