STIX Two Math, Lean 4.32.2 and the exact package revisions in
formal/dependency_manifest.json. One full source-independent command is::

  python3 -B -O check.py --out /fresh/absolute/path --programs --formal --render

All child mathematical Python programs run without optimization, with
PYTHONOPTIMIZE removed, so their original assertions remain active even
when the orchestration checker uses -O. GAP runs with user startup disabled.

  --verify-inputs --study-root /path/to/research/leemans

canonical Lean sources. --gap, --xelatex, --lean and --packages override
local tool paths. Without --programs, --formal or --render, the report
explicitly marks those components as not run; saved reports never substitute
for requested fresh execution. A fresh destination is mandatory.

The manifest is an export allowlist. It excludes primary assets, temporary
renders, compiled Lean objects and conversion scratch files. The saved author
