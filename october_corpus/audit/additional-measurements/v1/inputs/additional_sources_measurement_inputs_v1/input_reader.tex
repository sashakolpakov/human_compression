\section*{Encoding, scope and limitations}
All source Type1 text events are aligned to actual PDF font dictionaries, encoded bytes and embedded glyph outlines. The two chiral mathematical papers and the new program appendix receive the same audit for their legacy Type1 mathematical glyphs; their Unicode Type0 body text is unchanged and is not claimed to have a separate outline audit. The audit records 78 Type1 font dictionaries and 1,358 glyph classes. There are 660 occurrence-bound replacements in 52 classes, with actual page, byte, font, event and context evidence. All 68 pages and 88 exceptional or repaired glyph classes were visually inspected.

Only visible glyph identity is calibrated. A maps-to symbol assembled from a bar-and-stub glyph and an arrow remains two components; it is not collapsed to one character. A display-wrap hook in the new code appendix likewise has two glyph pieces. Its left hook has no asserted exact standalone Unicode equivalent and retains the literal extracted comma. That representation limit particularly affects UTF-8 comparisons. All wrap markers remain in the measured PDF costs; they are ignored only for the independent check that every literal program character is printed. No mathematical correction is made to either source text.

The matching contract retains the original extension and lattice theorem and the stated coordinate descriptions of toroids.
