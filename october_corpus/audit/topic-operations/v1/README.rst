Operations: current science and numerical audit
==============================================

This admission combines the reviewed N005 principal contract with the complete
existing N006 and N007 contracts under one 21-page common paper. N005 is one
additional original, bringing the fixed programme to 36 admitted and measured
originals, with 70 accessible originals awaiting recovery and 55 awaiting a
usable source. All 161 remain in scope.

The `papers and source table <../../../papers/topic-operations/v1/README.rst>`_
identify every current scientific document. All 81 + 27 + 32 source records
are preserved with their retained inputs, corrections and unresolved questions.
The frozen author labels are historical; `admission.json <admission.json>`_
is the current decision. It does not affirm every literal assertion in the
sources or add a new numbered-conjecture answer.

The `numerical reader <measurement/packet/reader.pdf>`_ and
`exact results <measurement/packet/results.json>`_ give a whole written factor
of 1.266700 and a factor of 0.357176 including complete raw software. The
conditional factors are 2.459966, 1.455365 and 1.860057 after acquiring the whole
common paper, all 23 mathematical/validation files, both decoding drivers and
required data. Whole common costs are charged once within the topic; separate
topics receive no overlap discount. No complete printed-program factor exists.

The independent review checks all 40 measurement settings and 200 exact
fractions, 640 acquisition integers, five CSV tables and actual SVG/PDF graph
coordinates. It reuses the separately accepted input counts, whose independent
recount covers 770 cells. The original graphic-event substitutions are declared
component proxies; raw and text-only sensitivities remain available. Full
outside proof, historical software, graphics and formalization costs remain
unknown. Data storage is reported separately from text lengths.

Run from the repository root, using Python with pypdf and Matplotlib::

  python -B -O audit/topic-operations/v1/replay.py --out /fresh/output

Add ``--render --xelatex /path/to/xelatex`` to rebuild all eight current paper
and partial-appendix routes and the numerical reader. STIX fonts are required.
Add ``--programs`` to run the complete N005 programs and controls. For a full
measurement recount, supply the exact user-owned editions::

  python -B -O audit/topic-operations/v1/replay.py --out /fresh/output \
    --recount --n005 /path/to/N005.pdf --n006 /path/to/N006.pdf \
    --n007 /path/to/N007.pdf

no private proof directory is required. Source PDFs and external Atlas data

`publication_plan/publication_map.json <publication_plan/publication_map.json>`_.
