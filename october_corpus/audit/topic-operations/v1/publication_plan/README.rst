Proposed publication of the complete Operations edition
======================================================

This is a private routing proposal, not a public admission or a numerical
comparison. The three originals are N005, N006 and N007, by Claudio Alexandre
Piedade and Philippe Tranchida. The accepted current written boundary is the
whole 21-page common theory and the full applications: N005 18 pages, N006 its
8-page general paper plus 5-page nine-case and 4-page Harada–Norton companions,
and N007 5 pages. All six scientific documents are charged; the old common
papers are archived editions, not additional free premises.

``publication_map.json`` lists every original file, exact hash, byte size,
proposed public route and role. The proposed new namespace is
``papers/topic-operations/v1`` / ``audit/topic-operations/v1``. Existing immutable
N006 and N007 resources remain at their ``topic-diagonal`` routes. The root may
select another namespace through a separately checked adapter. No existing
public or frozen file is changed by this packet.

Reproducible review
-------------------

From the authoring environment::

  python -B -O check.py --study-root STUDY --public-root PUBLIC --out FRESH \
    --stage-replays

After exact proposed copies have been installed, the same checker can use
only those public bytes (the study path is unused)::

  python -B -O check.py --study-root UNUSED --public-root PUBLIC --out FRESH \
    --published --stage-replays

Both modes were tested. The copied-only runs use the exact integrated binding
checker, distinct migration checker, citation checker and original boundary
checker. They do not rerun source extraction, GAP, Lean or TeX. Ten semantic
mutations are rejected. ``replay_routes.json`` records full optional scientific
and measurement commands; source PDFs, GAP catalogue data and toolchains stay
explicit external requirements. Numerical work is separately authorized after
the accepted input review, but no ratio is calculated in this mapping packet.

Before publication, root still needs the separately reviewed arithmetic packet,
a current publication guide/admission, catalogue changes, portable measurement
adapter and standard-verifier guard. This plan is not approval of those future
bytes or a source-count update.
