Portable replay and review roles
--------------------------------

The original input proposal and its independent review are retained exactly
under ``inputs/`` and ``independent/``, including their manifests. The root
agent reviewed the inputs and authored this numerical packet. Its arithmetic
and reader require a separate independent review. Author checks alone do not
provide that acceptance.

Arithmetic needs only Python 3, without source PDFs, GAP, Lean or a network::

  python -B -O compute.py --out /fresh/numbers
  python -B -O check.py --results-dir /fresh/numbers --out /fresh/check.json

The author checker verifies all 120 fractions, both CSV tables, complete
boundaries and sixteen corruption controls. For the reader, Python also
needs matplotlib and pypdf, together with STIXGeneral and XeLaTeX. The builder
uses ``/opt/homebrew/bin/xelatex``; adjust that executable path for a different
installation before building a new, separately identified reader::

  python -B -O build_reader.py --out /fresh/reader

The frozen reader has two pages and no TeX diagnostics. Its author visual
review covers both pages. Later acceptance must bind the exact frozen files
and preserve the distinction between input review, arithmetic review and
the earlier independent mathematical review.
