Historical quartic input set
============================

Bounded L059 component, not a whole-source recovery.
Read historical_quartic.tex and scope.json for the exact borrowed coverage
and historical census premises. The source cutoff is explicitly corrected.
No old identifier or ordered-colour correspondence is inferred.

Replay (pynauty and GAP required)::

  python check.py --sources /path/to/L059_recovery_work --output /fresh/directory/report.json

The source directory must contain the exact primary inputs in inputs.json.
The checker also writes its exact GAP order input and terminal output beside
the report. It rejects optimized Python, verifies every input hash and
requires a clean GAP terminal pass.
