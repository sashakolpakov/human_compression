Append test and search completeness
----------------------------------

A C-marking is independent, by applying IP to a singleton and its
complement. Its prefixes and all their submarkings therefore have IP.
For an admissible appended involution x, the old prefix supplies the first
end deletion. In the recursive suffix test, its old prefix is a submarking
of the original prefix and again has IP. Thus the retained end-intersection
criterion is applicable at every recursion, with two distinct involutions
as the base case. The recursive implementation is not a general IP test
on arbitrary tuples without this precondition. The final comparison uses
all subset intersections independently of that abbreviated recursion.

At each node the candidate set is invariant under its pointwise prefix
stabilizer. A conjugacy between extensions must send their prefixes to
equivalent prefixes; uniqueness at the preceding depth makes these equal,
so the remaining conjugacy lies in the current stabilizer. This establishes
one representative per ordered permutation-marking orbit. The action may
have a kernel; nothing requires faithfulness. The implementation uses
actual permutation conjugation and successive centralizers in S11.

For a prefix of length m, every future mark commutes with its first m-1
entries. All future marks therefore lie in the complete current pool.
If the group generated by the prefix and that whole pool is intransitive,
no subgroup generated by a continuation is transitive. The implementation
uses the entire pool for this test and intersects the pool with the last
old centralizer on extension. It does not substitute orbit representatives
for the pool. A proper transitive subgroup is recorded and still extended.
Only the depth bound or generation of all A11 ends an otherwise viable
branch. The latter termination follows from independence, not transitivity.
