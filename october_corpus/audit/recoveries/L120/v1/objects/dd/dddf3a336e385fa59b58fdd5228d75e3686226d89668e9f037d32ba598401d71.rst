Connected prefixes for the fixed target groups
===============================================

For n>=5 the groups A_n and S_n are directly indecomposable. For A_n this follows from its retained standard simplicity. If N is a nontrivial normal subgroup of S_n, simplicity implies N intersection A_n is either A_n or 1. In the latter case [N,A_n] lies in that intersection, so N centralizes A_n. But the centralizer of A_n in S_n is trivial: an element centralizing all3-cycles preserves every3-element support, which fixes each point when n>=4. Thus every nontrivial normal subgroup contains A_n. Two nontrivial direct factors in S_n would then have nontrivial intersection, a contradiction.

If adjacent marks at indices j,j+1 commute in a string C-marking, all marks on the two sides of that cut commute. Their generated groups are nontrivial, commute, and have trivial intersection by IP. They generate the whole group, hence give two nontrivial direct factors. This is impossible for either fixed target. Therefore every adjacent product has order greater than2, and every prefix containing a commuting adjacent pair can be rejected permanently. No later mark can repair that cut, because the string relations force all later marks to commute with the earlier side.

At a prefix, commutation with the last mark is invariant under its pointwise centralizer St. The new filter removes whole St-orbits. It therefore preserves precisely the connected-prefix portion of the inherited enumeration, with unchanged minimum representatives and actual IP tests. Completeness for the fixed target follows from the direct-factor argument. The new engine is not a census of all transitive proper subgroups; it retains exactly those with connected marked diagrams. This changed ancillary scope is explicit. Complete small results are compared with old literal records filtered by every adjacent product order>2; target counts are separately required identical.
