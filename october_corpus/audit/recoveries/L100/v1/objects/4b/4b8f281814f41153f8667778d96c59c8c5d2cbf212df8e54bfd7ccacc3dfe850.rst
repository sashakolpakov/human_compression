Literal incidence and palette postprocessing for L100
===================================================

Exact input and purpose
-----------------------

The complete acquired augmentation covers all95 fixed subgroup anchors with
REQUIRE_2T=false. Its145 rank-at-least-two specified-G families have already
been partitioned under full Aut(G) and type permutation. The accepted partial
and incremental callers retain every membership witness and negative complete
comparison premise. Their final29 representatives have ranks2,3,4,5. This
component takes that exact result; it does not rerun augmentation, recompute
Aut(G), or treat printed source counts as expected output.

An automorphism carrying the parabolics of one family to another, with a type
permutation, induces an incidence isomorphism on the cosets. Thus every input
geometry is isomorphic to one of the acquired29 representatives. It remains
possible that two representatives admit an incidence isomorphism not accounted
for by the specified-G equivalence. The present caller checks this remaining
question and computes full correlations and type-preserving automorphisms of
each literal geometry. Group names, source diagrams, local action descriptions
and all construction/truncation joins remain distinct obligations.

Literal cosets, incidences and action
------------------------------------

Fix the exact accepted permutation group G and its ordered list E=Elements(G).
For each maximal parabolic P_i, choose the actual RightTransversal returned by
GAP. A typed object is a right coset P_i x, stored as the set of positions in E
of all h*x for h in P_i. The code checks every coset size, disjointness and
complete coverage of E in each type. It records the resulting typed partition;
no assumption about independently generated transversal labels is needed.

For each g in E join its containing cosets in every two distinct types. Two
objects are joined exactly when their sets have a common element: membership
of g produces every emitted edge, and any common element is visited. This
constructs the full incidence relation, including all nonincidences, without
using local orders or a source drawing. Graphs have no within-type edges.

For each fixed generator a of G, the object permutation sends P_i x to P_i x*a.
The implementation checks this on every element of each stored coset, then
checks the resulting permutation against every adjacency row and every type.
It also checks that the generated object action has order |G|, hence its
kernel is trivial. This is an exact finite action check, not a claim of full
geometric automorphism completeness. Source left cosets gP_i correspond to
right cosets P_i g^{-1} by inversion; under this coordinate map left
multiplication by a corresponds to right multiplication by a^{-1}. Incidence
and type partitions are unchanged by this explicit convention transport.

Acquired marker construction and full groups
-------------------------------------------

We reuse the palette-vertex construction in the accepted R188Pair implementation
(phase188_gadget_check.g) and the final verification paragraph of the reviewed
phase197 recognizable-representations manuscript. The code here uses adjacency
lists for the identical edge predicate. For clarity, the entire argument at
this join is as follows. Attach one marker m_i adjacent to exactly the objects
of type i. Distinguish two colour cells: all objects and all markers. Every
colour-preserving automorphism of this augmented graph restricts to an
incidence automorphism permuting whole types, because the marker neighbourhoods
are exactly the nonempty type classes. Conversely any such correlation extends
uniquely by its type permutation. Nonempty distinct classes imply that an
extension fixing all objects fixes every marker. These inverse maps identify
the full augmented group with the correlation group on objects.

Fixing all markers individually is precisely fixing every type. Consequently
the kernel of the action on markers is the full type-preserving group. The
caller computes both this kernel and the pointwise marker stabilizer and checks
their equality. Its object restriction is checked faithful. This avoids an
uncoloured incidence-graph shortcut and does not require equal or distinct type
sizes. Every returned correlation generator is checked literally on both
colour cells and every augmented adjacency row; the specified right G-action
is checked contained in the resulting typed group.

AutGroupGraph is used in its full, nonrandom GRAPE/nauty mode. Its complete
group and negative isomorphism decisions retain the explicit exact finite
software premise; generator checks alone would prove only a subgroup. The
actual dreadnaut executable, GRAPE implementation and JSON input/output library
are pinned. No old canonical labelling is imported. GraphIsomorphism uses its
default fresh-labelling route on records containing the augmented graph and
the two colour cells. Every positive output is also checked directly on both
cells and all adjacency rows. Objects of different rank or different sorted
type sizes cannot be isomorphic; these are only necessary rejection filters.

Sequentially compare each new representative with previous bare-geometry
class representatives. A positive checked map places it in that class;
otherwise the complete negative graph comparisons establish a new class.
Together with the acquired specified-G membership maps, this covers all145
input families. No equality of labelled enumeration multiplicities is inferred.

--------------------------

small interface controls, not an L100 census or full-data graph run.
