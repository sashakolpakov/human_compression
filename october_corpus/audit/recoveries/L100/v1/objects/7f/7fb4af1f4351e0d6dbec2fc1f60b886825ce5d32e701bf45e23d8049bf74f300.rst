Bounded partial full-automorphism fusion for L100
================================================

This is an author operational and finite equivalence interface. It acquires
exact clean returned-anchor records from three previously reviewed jobs:
95..12, 11..3, and 2. Their union is exactly95..2, with no repeated anchor.
Anchor1 remains unpaid. Rank1 input families are recorded but excluded from
this rank-at-least-two fusion. The103 remaining input families have counts
21,25,57 in ranks2,3,4 before full automorphism/type fusion. These are actual
completed-input counts, not assumptions about any printed source count.

The preflight binds all three exact receipts, every input and output recorded
there, and all scientific and operational acceptance chains. It rejects a
changed receipt, unaudited boundary, missing empty final level, nonempty stderr
or duplicate/missing anchor. The generated GAP driver loads the exact accepted
fixed-model catalogue and loader. No new IsomorphismGroups choice, table action,
partial anchor1 file, augmentation function, or legacy 2T truncation filter is
loaded. Every actual done file is bound before the call and rechecked afterward.

A completed panel tuple T=(T_i), with B its acquired Borel, determines the
maximal parabolics P_i=<T_j:j != i>. The caller checks the full generated group,
B=intersection(P_i), and T_i=intersection(P_j:j != i) literally. These identities
are consequences of the acquired recognized families and are checked at this
join rather than inferred from subgroup orders. Local2T is not a filter.

The rank-two archive has been read for reusable full-Aut data. Its result.g
retains no complete automorphism generator list; pair_witnesses.g contains24
individual positive maps, and its two former callers computed AutomorphismGroup
transiently. A separate advisory read by l044 confirmed this inventory. Those
positive maps do not certify that their generated subgroup is all Aut(G).
Therefore this caller makes one explicit GAP AutomorphismGroup(G) call on the
same literal fixed G. It saves the actual fixed group generators, full-Aut
order and each full-Aut generator's images on the fixed generators in
``automorphisms.g`` BEFORE any family comparison. Each such map is reconstructed
as a bijective GroupHomomorphismByImages and compared on the original generators.
Completeness is the retained GAP algorithm premise, not a 21-point normalizer
or an inference from the value of the resulting order. If later fusion times
out, these bytes remain with an exact receipt for a separately checked reuse.

The original AutoSub, Signature and EquivalentFamilies functions are copied
byte-for-byte from phase7_sporadic_fuse.g. FindFamilyWitness is a certificate
companion implementing its same successive-stabilizer search. For each type
permutation, after matching positions1..i, the remaining search group is the
pointwise stabilizer of those target subgroups. RepresentativeAction finds one
map of the next subgroup or establishes that none exists in that group. Any
other such map differs by an element of the next stabilizer. Induction thus
covers every simultaneous image. Signatures and subgroup orders only reject
impossible matches. Generator images are updated sequentially, so no implicit
convention for multiplying maps enters the certificate. Every positive result
is reconstructed and all actual subgroup images checked. Every candidate,
including a newly chosen representative, receives a checked positive map to
its representative; the identity is recorded for a new representative.

Sequentially comparing each candidate with existing class representatives
therefore partitions exactly the stated finite input set under full Aut(G)
and type permutation. The complete tiny control independently enumerates all
automorphisms/type permutations for538 comparisons, matching both the unchanged
Boolean test and new witness test. It includes non-2T abelian panels, rejects
corrupted maps/palette permutations and checks explicit relabelling transport.
A separate actual-caller control closes three C2^2 families into one class,
then reads back its saved full-Aut and family data.

A single external60-second cap covers loading, reconstruction, Aut computation,
and comparison. The unchanged accepted phase function writes ACTIVE before
launch, kills/waits for its own process group on a deadline, and retains all
stdout/stderr and generated artifacts. All input pins are rehashed afterward.
Only a clean terminal zero, unique final marker and complete result yield
COMPLETE_PARTIAL_INPUT_FUSION. A deadline is PARTIAL_POSTPROCESSING_DEADLINE;
its partial journal does not receive a completed-classification claim. There
is no automatic continuation. Receipt flags distinguish target_postprocessing
from target_census; neither a new subgroup census nor a graph enumeration runs.

This is specified-G Aut/type fusion only. It neither proves bare-incidence
isomorphism classes nor full geometric Aut/Cor groups, truncations, exact source
counts, the missing anchor, or whole-original completion. Those later interfaces
remain in route.rst. Root requested the fixed input and saved full-Aut boundary;
publication_recovery authored this caller/certificate adaptation. The old engine
and all accepted records remain unchanged. No new mathematical source, Lean,
measurement, or publication action is involved.
