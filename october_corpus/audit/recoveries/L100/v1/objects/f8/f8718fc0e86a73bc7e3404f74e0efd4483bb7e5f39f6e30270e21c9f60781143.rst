L100: next finite equivalence and full-group interfaces
=====================================================

Status: private preparation/read-only reuse plan. No new computation, target,
full catalogue or source claim. The95-anchor augmentation remains separate;
only complete audited anchors may enter a declared partial input inventory,
and all95 are needed before a full exhaustion result.

1. Exact specified-group automorphism fusion
------------------------------------------

The functions AutoSub, Signature and EquivalentFamilies are extracted literally
from phase7_sporadic_fuse.g into legacy_fusion_functions.g. They use all of
Aut(G), all type permutations compatible with subgroup orders, and successive
stabilizers to decide simultaneous transport of the full parabolic family.
The finite signatures only reject impossible equalities. The complete orbit
test supplies the remaining decision, under the accepted GAP group-algorithm
premise. This is the existing method, not a new fusion theorem.

The surrounding old initialization must not be reused: it loads a fresh table
of marks action, whereas the accepted L100 input has a fixed checked transport
to its saved21-point permutation group. The new caller must load exactly
input_catalogue01.g/catalogue_loader_v2.g and evaluate every saved subgroup in
that same G. It must never infer a model identity from name or order alone.

The input join is explicit: for every completed Borel ID, acquire its unique
terminal receipt, done file and all supporting checkpoint/input pins; reject
duplicate or conflicting IDs. Reconstruct parabolics as joins of all but one
panel, including the saved Borel if needed, and independently check the exact
panel/Borel reconstruction. Report local two-transitivity as an output only.

In addition to the unchanged Boolean fusion test, store literal witnesses for
each positive identification: type permutation and images of the fixed G
generators. Reconstruct and check a bijective GroupHomomorphismByImages and
verify every actual parabolic image. The sequential image updates can be saved
without assuming an unstated convention for multiplication of automorphisms.
Negative fusion decisions retain the complete Aut(G)/type search premise.

This step classifies the specified G-actions under automorphisms of G and type
permutation. It does not by itself identify bare incidence isomorphisms, nor
prove the full correlation group or type-preserving automorphism group.

2. Reuse the accepted palette-vertex encoding
-------------------------------------------

The R188Check/Data/Graph/Pair functions are extracted literally from the already
reviewed phase188_gadget_check.g. The same encoding and explicit palette-action
checks appear in phase197_finite_groups.g and the final paragraph of
phase197_recognizable_representations.md. Their existing F010/representation
provenance and acceptance are to be acquired; no new representation theorem or
new-source credit is intended.

For each actual right-coset geometry, form one object vertex for each typed
right coset. Join two objects of different types exactly when the cosets meet.
An efficient exact construction enumerates the20160 elements once and joins,
for each element, its containing cosets in every pair of types. The union is
precisely nonempty intersection. Save coset representatives/partitions and the
action of each fixed generator, not merely a group order or unnamed graph.
Check the right-action maps against all vertices and incidences. The earlier
left-coset source convention is transported by inversion explicitly.

Add one marker for each nonempty type, adjacent to exactly its object vertices.
There are two distinguished colour cells: all objects and all type markers.
Colour-preserving automorphisms of the augmented graph are exactly correlations:
the marker neighbourhood determines a type, and restriction/extension are
inverse because every type is nonempty. Fixing the markers individually gives
the type-preserving group. These are the acquired palette-encoding arguments,
not an inference from arbitrary uncoloured graph automorphisms.

For bare incidence comparison, use GraphIsomorphism on records
rec(graph:=augmented_graph,colourClasses:=[object_vertices,marker_vertices]).
The installed GRAPE code at lines5496--5565 explicitly supports this interface.
Use its default fresh canonical-labelling route; do not reuse persisted labels
from a different environment. Every positive isomorphism must also be checked
literally on both colour cells, every marker/type assignment and all adjacency
rows. Nonisomorphism and full-group completeness retain the explicit native
GRAPE/nauty software premise, with actual executable/library/version pins.

The same marker graph yields Cor and Aut. Save their literal generators, verify
every generator, compute the actual action on the marker set, and verify that
its kernel is exactly the type-preserving subgroup and that its restriction
to object vertices is faithful. Group names/extensions, if claimed in source
rows, require their own exact identifications beyond orders.

3. Truncations and source joins
-----------------------------

The old fusion file's final truncation loop explicitly skips non-2T lower and
higher objects. It is outside this reuse. Enumerate every required subset of
the actual higher object's types with no2T filter, compare the literal induced
incidence graph to the lower object using the marker encoding, and preserve
the resulting explicit object/type map. For a specified-G truncation the
simultaneous parabolic test is useful, but a bare-geometry statement still uses
the literal incidence map. The accepted PG(2,4) eight truncations provide small
existing positive controls and exact fixed-model comparison targets.

Source diagram invariants, actual local-2T flags, Aut/Cor groups, fusion counts,
and construction labels remain distinct fields. The printed rank counts are
not assumed as acceptance predicates. In particular the already corrected
rank-two class2.2 and both constructed rank-five models have non-2T panels.

4. Bounded controls before any complete-data postprocessing
----------------------------------------------------------

Use previously closed tiny group families to compare unchanged Aut/type fusion
against literal automorphism-and-type enumeration. Include a non-2T panel and
transport the same group to a deliberately different permutation labelling.
Reject an untransported checkpoint and a corrupted automorphism witness.

For the palette interface, check small literal coloured graphs against complete
permutation oracles: accepted vertex/type renamings, rejected altered incidence,
two equal uncoloured graphs with incompatible type partitions, and allowed
permutations of distinct markers. Check full Aut/Cor and the palette kernel.
These are bounded interface checks, not another L100 census.

Do not execute a full-data fusion/gadget pass until its finite input inventory,
caps and exact caller are separately reviewable. Initial partial inventories
must remain labelled partial. No whole-source conclusion follows from this
plan or from an agreement with some printed counts.
