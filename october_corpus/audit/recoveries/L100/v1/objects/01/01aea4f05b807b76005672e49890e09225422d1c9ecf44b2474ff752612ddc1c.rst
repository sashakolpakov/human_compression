Reconstruction and partition proof
----------------------------------

All work takes place in the same literal G on the accepted fixed generators.
For each saved automorphism generator image list, reconstruct the homomorphism
on G and check bijectivity. Their generated subgroup A has the saved complete
order. Because these are the exact image lists saved by the acquired complete
AutomorphismGroup call, A is the same complete Aut(G); equality is not deduced
from an unrelated numerical order. No AutomorphismGroup call appears in the
new production function. The group size check detects faulty reconstruction.

For each new panel tuple T=(T_i), reconstruct P_i=<T_j : j != i>. Check literal
membership, full generation, intersection(P_i)=B, properness of each P_i and
T_i=intersection(P_j : j != i). These are joins to acquired recognized families;
they do not replace their already completed flag/incidence recognition. No
local-2T filter is added. Source member identities (anchor,index) must be
unique within each input and disjoint between old and new inputs.

Copy the old representative list and old member-witness list unchanged.
For each new family in each rank, compare it with every existing representative
of that rank until the exact acquired FindFamilyWitness succeeds. It exhausts
all type permutations and the successive stabilizers of the already matched
parabolics. Thus failure means no element of A with any type permutation maps
one family to the other. If no comparison succeeds, append the new family as
a representative. Record an identity witness for a new representative, or the
found witness otherwise. Reconstruct and verify every new positive map on all
parabolics using the acquired CheckFamilyWitness function.

Inductively, before each new family the retained representatives are pairwise
inequivalent and cover all families processed so far. A successful comparison
extends coverage without changing representatives. If every comparison fails,
the added representative is inequivalent to all previous ones. Equivalence of
two old representatives cannot change when a new family is inserted: it is
a fixed equivalence relation under the identical A and type permutations.
This proves that no old comparison or membership classification must be rerun.
At termination the combined representatives partition precisely the acquired
103 old plus 42 new families. The old 103 member records remain verbatim GAP
values, and the new 42 maps are separately retained in new_witnesses.g.
