Installed LINS interface inspection
===================================

This is a bounded read of the actual installed LINS0.9 (PackageInfo.g,
15March2024), not a group census or independent proof of the package.

LINS.gd lines224–243 defines LowIndexNormalSubgroupsSearchForAll(G,n) as
all normal subgroups of G of index at most n. LINS.gi lines464–466 calls
LowIndexNormalSubgroupsSearch(G,n) with no options. The defaults at252–262
set UseLIS=false, DoCut=false and DoTerminate=false; both p-quotient and
intersection options return true. Thus no requested early-stop or partial
cut mode is implicit in this exact entry point. Completion still requires
an actual successful terminal execution of the call.

The index guard in LINS.gi lines297–344 uses
min(LINS_TargetsCharSimple_Index,LINS_TargetsQuotient_Index). Both installed
tables declare10000000. An index exceeding it enters Error with an explicit
warning that continuation may omit normal subgroups above the bound. A
caller must reject that condition, not continue from an interactive break.
UseLIS has a separate bound, but is false in this entry point.

Output nodes represent normal subgroups (kernels), not isomorphism classes
of quotients. Distinct kernels can have isomorphic abstract quotients. The
manual's elementary-abelian example explicitly returns806 isomorphic C5^2
subgroups. Marked quotient equivalence, reversal or diagram automorphisms
need their own exact convention and subsequent test; an abstract-group
StructureDescription cannot supply such a quotient of the output list.

The nonsolvable coverage is not a classification-free primitive. The
characteristically-simple table supplies every T^d in range and the prime
divisors of its Schur multiplier. The quotient table supplies groups Q
between T^d and Aut(T^d) whose action on factors is transitive. The actual
createTables.gi obtains T from SimpleGroupsIterator, constructs automorphism
groups and their outer quotients, enumerates subgroups there, tests factor
transitivity, and uses cohomolo SchurMultiplier(CHR(T,p)) for the other
table. Those finite-simple/classification and table-generation interfaces
are retained input costs unless independently reproduced. I inspected the
actual table declarations and generator source, but did not regenerate
tables or audit every entry. The normal-subgroup search algorithm is
attributed in the installed manual to Firth's2005 work and its later
implementations. No package correctness or target completeness is claimed
from this interface inspection alone.
