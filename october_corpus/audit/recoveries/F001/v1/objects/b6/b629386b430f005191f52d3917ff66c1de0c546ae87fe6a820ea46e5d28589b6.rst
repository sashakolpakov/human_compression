F001: negative reflections only
==============================

The four-page proof bounds the rank by five when every generator of the
full Omega(5,q), q odd >=5, is a negative reflection. It retains the
finite reflection classification, group order formula and simplicity.
The proof gives a stronger endpoint statement for connected six-term
strings. Mixed involution types are not covered, and whole F001 remains
pending. No original, conjecture, Lean or measurement credit is granted.

The checker verifies exact Gram determinants, the six-root B5 model and
its 3840-element signed permutation group, scopes, byte bindings and
optional native rebuilding. It does not formally verify the uniform
proof. Run with an unused output path and Python with pypdf installed::

  python check.py --out FRESH --study-root STUDY --render

Source PDFs are private retained references, not redistributable packet
exports. The fixed source edition and earlier auxiliary refutation are
provenance only. No accepted predecessor files were modified.
