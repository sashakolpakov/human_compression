Disconnected strings in two Coxeter families
============================================

This three-page note recovers and qualifies the I2(m) and H3 portions of
F006. Read disconnected_strings.pdf for the complete arguments, attribution
and exact scope. The fixed source permits disconnected strings; under that
convention the maximal rank is not always the Coxeter diagram rank.

The dihedral result is proved uniformly. The H3 census is an exhaustive
120-element computation using only Python's standard library. The retained
report lists every class representative. The proof specifies all pruning,
rank bounds, equivalences and the retained classical Coxeter order. Correct
execution of the code is the explicit computational premise. There is no
Lean claim, whole-manuscript recovery or open-conjecture credit.

Run check.py --out /an/unused/directory with Python, pypdf and pdflatex.
The optional --source-root points to the private source archive and checks
the fixed PDF binding. The executable itself needs only the exported files.
A distinct mathematical and code review is still required before acceptance.
