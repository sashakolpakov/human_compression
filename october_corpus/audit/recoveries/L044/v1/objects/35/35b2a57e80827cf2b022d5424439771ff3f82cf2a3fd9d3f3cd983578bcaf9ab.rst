Attachment interface for the connected core
===========================================

This is a substantive clarification added by l044_resume while preparing
root's two_neighbours_route.rst for TeX. It is not yet independently
reviewed and must be read together with the actual contracted forest.

Assume J is connected on Y, with every selected C edge a bridge in the
connected graph J union E_C. Contract J to a single vertex. The selected
C edges form a tree Q. Each connected component of the selected graph
on the outside vertices has precisely one edge to Y; two would create
a cycle in Q. Call that edge its exit. Every additional projected C
edge lies in Y, as proved in the common graph argument.

Claim: any C mark whose selected edge has both endpoints outside Y
commutes with K=<l,r,s>.

Suppose instead that such a mark c fails to commute with K. It already
commutes with l, so it fails to commute with r or s. Since r,l,s are
consecutive, c is the outer neighbour of exactly one of r,s. Follow the
outside tree from the selected c edge towards its exit e. The successive
selected edges along this path have distinct labels, and consecutive
labels fail to commute. Indeed their projected transpositions share an
outside vertex. If both other endpoints are outside, their restrictions
there are two transpositions with exactly one common endpoint. If one
other endpoint is in Y, evaluate at the outside endpoint of the other
edge: one order sends it into Y and the other sends it to the shared
outside vertex. Additional edges lie in Y and cannot cancel this
disagreement. Thus this is a path of noncommutation from c to the exit
label e. All its labels belong to C; none is r,l,s, and c differs from e.

The exit mark e also fails to commute with K. Otherwise it centralizes
K and preserves its unique orbit of size2|Y|, which is distinguished
from all the outside orbits of size2; it could not have an exit edge.
It is therefore the outer neighbour of r or s. It cannot be a second
outer neighbour of the same R mark as c, because that mark already has
l as its other neighbour in the string. Thus c,e attach to opposite
ends of r-l-s. Their outside noncommutation path, together with these
two attachments and r-l-s, is a cycle in the noncommutation graph. That
graph is a subgraph of a path, contradiction.

Hence all selected outside marks commute with K. In the two TT core
forms A/B of the root proof, the labelled eight-point K path has trivial
centralizer. Such marks fix the core pointwise, so their global row
character is zero and no extra projected Y edge occurs. They are exactly
the plain doubled selected transpositions. This now justifies every
plain-tail premise in the TT exit calculations, including any C label
which occupies a neighbouring string position but happens to commute
with its adjacent R mark.
