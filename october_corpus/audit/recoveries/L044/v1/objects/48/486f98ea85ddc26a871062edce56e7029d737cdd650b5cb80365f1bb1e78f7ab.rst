Working review of the one-neighbour binary equality argument
============================================================

Verdict
-------
The complete snapshotted hand argument is sound. I found no substantive gap
in the row-preserving branch or its two local intersection-property
contradictions. The row-interchanging branch is a valid reduction to the
separate two-neighbour case, not an independently completed exclusion. The
future statement must preserve that dependency, and the two-neighbour proof
must not in turn depend on a completed one-neighbour result in a way that
creates a cycle. No diagnostic output was used as a mathematical premise.
This is a working review, not acceptance of a frozen TeX edition.

Acquired setup and the swap reduction
------------------------------------
The natural alternating action, actual IP, n=2m with even m>=8, rank m,
transitive binary omission H, and intransitivity of every H_j are essential.
The safe contraction proof supplies the precise support alternatives. If h
swaps rows, <l,h> has one orbit of size six and all others of size two. If
all C centralize h, they also centralize l, so all H preserve that unique
six-point orbit, contradicting transitivity. Thus some c fails to commute
with h, and string relations leave exactly R'={l,c} when h replaces l as
the distinguished swap. Nothing else in the standing setup changes. This
is an exact passage to the root's two-neighbour configuration.

The tree and confinement of extra C edges
----------------------------------------
The two simple h edges have graph rank two. Every selected C edge is a
bridge after all these edges are adjoined: any alternate walk would lift,
using l, to a walk in its actual omission subgroup. There are m-3 such
bridges, so the resulting simple graph has rank m-1 and is a tree T.

For an additional actual C edge, its T-path can use only h labels and its
own one selected C edge. If the latter occurs, neither endpoint of this
new edge can be incident to it, since each C mark acts as a matching on
pair indices. Thus the path must be h,c,h. Otherwise the path uses only
the two h edges. In either case both endpoints lie in Y, the h support
on pair indices. This also covers an extra edge parallel to an h edge.
No action of h on pairs is assumed at this step; only C have that action.

Every C mark except the other neighbour c of h centralizes <l,h>. Its
large joint orbits (size four or six) distinguish Y from the remaining
two-point orbits, so it cannot exit Y. A selected exit is necessary for
T to be connected, so c exists and its single selected edge is the unique
exit. There are no additional unselected exits, by the preceding argument.
The induced tree on the complement of Y is connected: removing the unique
exit from T separates precisely Y from its complement.

Disjoint h edges
----------------
With four Y vertices and a single exit, the tree on Y has exactly three
edges: h,g,h. Equivariance of g under <l,h> forces it to interchange the
two four-point joint orbits, hence its projected matching moves all four
Y vertices, including the exit vertex. Its selected edge and every extra
g edge are within Y, so it fixes all outside indices. Consequently g and
c do not commute. The outside endpoint of c has an incident tree edge d,
because the outside tree has at least four vertices. The same direct
endpoint comparison shows [d,c]!=1, even if d has an extra edge in Y.
Together with [h,c]!=1 these give three distinct noncommuting neighbours
of one string mark. The contradiction is valid.

Path support and the central-involution route
--------------------------------------------
For h=(a0 u0)(u1 b1), the l/h graph is the alternating six-point path.
Its common permutation centralizer on that orbit has only the identity
and path reversal. This can be seen directly: an equivariant permutation
must send an endpoint fixed by h to one of the two endpoints, after which
commutation propagates its values along the entire path. Reversal has
pair permutation (a b) and exchanges the binary rows; identity has neither.
Every C mark is diag(pi) l^chi. The pair projection of <C> is faithful by
actual IP, since its kernel is contained in <l>. Thus chi descends to a
genuine character of the projected group, not merely a list of signs.

If the exit is at u, its only optional additional C edge is (a b).
The element z'=(lh)^3 is diag((a b)) l and is the identity-free central
reflection of <l,h>. Both possible c projections commute with (a b),
regardless of chi(c); hence all H centralize z'.

The maximality lemma is correct, with one wording clarification. The
intransitive H_j projecting onto P has two ORBITS meeting each new pair
once. They are sections of the z'-pairs, not necessarily the original
binary rows. If its kernel contained z', projection transitivity would
make it transitive on all 2m points; hence its projection is faithful.
This supplies a genuine marked isomorphism with P, of rank m-2. If all
m-1 projected marks were independent instead, the acquired extremal
symmetric independent-generator theorem forces P=S_m. In the redundant
case, complete L047 forces P=A_m or S_m, including its degree-eight rank-six
boundary exclusion. The alternative pair system is therefore maximal.
The acquired parent pair-block theorem applies with its explicit
smaller-degree induction. Bind the full Whiston/extremal input and the
full pair-block proof; neither should be left as an unnamed assumption.

Outer exit and the character contradiction
-----------------------------------------
For an exit at a, any g!=c whose Y restriction is reversal fails to commute
with c by evaluating at a: one composite leaves Y and the other stays in Y.
The selected tail edge at the outside endpoint x is also noncommuting with
c; since h already is a noncommuting neighbour, these two labels must be
the same if a reversal occurs. Every other C mark has trivial Y action.

Adjacency of distinct selected outside edges forces noncommutation of
their projected transpositions, independently of extra Y action. Thus the
outside tree has degree at most two, since a branch would yield three
pairwise noncommuting marks. Its root x has degree one: c already has h as
one neighbour and cannot have two additional incident tail labels. It is
therefore a path beginning at x. Include this endpoint argument explicitly
when writing the manuscript; the current sentence about string relations
compresses these two separate observations.

If g contains (a b), c cannot contain (b u): those edges would connect the
entire C projection graph, making <l,C>=H_h transitive. Without that extra
edge the projected first marks are (a x), (a b)(x y), (y z). The first two
generate the transitive dihedral group on four points, and conjugates of
(y z) by it give all star transpositions from z to those four points.
They generate S5; successive tail edges enlarge it to S_(m-1), fixing u.
The tail transposition (y z) has character zero and is odd, forcing this
character of S_(m-1) to be trivial. But g has character one, contradiction.
Thus all other C marks are ordinary doubled tail transpositions. If c has
no extra (b u), the same character argument on S_(m-2) makes chi(c)=0.

Extra (b u): first exact IP contradiction
----------------------------------------
For c=barc=diag((a x)(b u)), I checked the displayed words directly with
right permutation multiplication. On row zero hc is a four-cycle and on
row one it is (a x). Thus v=(hc)^2 is the pure row-zero element
(a u)(b x). Conjugation by lhl changes it to (a b)(u x); their product is
c0=(a x)(b u) on row zero. Consequently A=<l,h,c> contains c1=c*c0.

In B=<h,c,d>, with d=diag((x y)), (cd)^3=diag((b u)). Multiplying this by h
yields a pure row-zero three-cycle on a,b,u. Its c-conjugate involves x and
the same other two points. The two cycles act transitively on four points
and lie in A4. Their group has order divisible by four and by three, so is
all A4; it contains c0 and therefore c1 too. Meanwhile <h,c> has order eight
because hc has order four; its row-zero image is already D8 of order eight,
so that restriction is faithful. Nonidentity c1, supported solely on row
one, cannot lie in <h,c>. Actual IP requires A intersect B=<h,c>, giving the
claimed contradiction. This is a uniform word proof, not a finite census.

Extra (b u): row-interchanging c
-------------------------------
For c=barc*l, e=(cd)^3=diag((b u))*l. Direct multiplication of (he)^2 gives
the same three-cycle in both rows on a,b,u; it is identity on every other
pair. Its c-conjugate is the diagonal cycle involving x, so these generate
diagonal A4 on a,b,u,x. The actual d attaches y. Its conjugates by this
transitive A4 are every star transposition from y to the four points, so
B contains diagonal S5, in particular barc. Then barc*c=l belongs to
<h,c,d>, contradicting IP for the distinct singleton mark l. The l action
outside these five pairs is retained throughout this calculation: it
cancels in q and is recovered globally in barc*c. No hidden restriction
kernel is used.

Canonical endpoint exclusions
-----------------------------
The remaining actual marks have noncommutation graph exactly the connected
path l,h,c,d,... . Removing an interior label from a parent string would
split the remaining noncommutation graph into two nonempty disconnected
parts, so the omitted label must be an endpoint.

Before l, the omitted mark centralizes J=<h,C>. Its four actual orbits have
sizes m-1,m-2,2,1, all distinct. The first two induced actions are full
natural symmetric groups, whose centralizers are trivial. The mark can
therefore only interchange the two-point orbit, an odd permutation.

After the tail, it centralizes K=<l,h,C without the last mark>. K has one
orbit of size 2(m-1) and one isolated pair. On the large orbit, products of
conjugates h_x=(x0 u0)(u1 b1) generate the pure natural A_(m-2) on O'0 union
{u0}. Any permutation commuting with K preserves this support and
centralizes the alternating action, so fixes it pointwise (m-2>=6). The
centralizer of a transitive action is semiregular; fixing one such point
forces identity on the entire large orbit. Only an odd interchange of the
isolated pair remains. Both endpoint exclusions are complete.
