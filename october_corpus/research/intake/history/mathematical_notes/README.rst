Unmatched mathematical notes
============================

This collection preserves 5,856 unique .md, .tex, .lean, .bib and .rst files:
38,524,145 raw bytes with 7,308 original alias paths. Known committed files,
already archived ignored sources and new-packet counterparts were excluded
using the frozen working-file inventory. Mathematical ideas and source notes
are retained without admitting them as proved results. Python, API and SDK
helpers and third-party paper PDFs were not selected.

manifest.json lists the ordered parts, sizes and SHA256 hashes. Concatenate
the listed parts in order to obtain one tar.xz stream; each part is at most
32 MiB. The tar contains selection.json, unique.jsonl, aliases.jsonl and
deduplicated objects/<sha><suffix>. The JSONL metadata maps preserved bytes
to their original relative working paths.

Every source body was checked before writing and again while copying. Every
compressed part and every tar member was independently checked for complete
size and SHA256 equality through a streaming read. No note content, Original
scientific value or mathematical program was parsed or evaluated. Compression
used preset 3 and 64 KiB reads; RSS checks stayed below 128 MiB. This collection
adds no proof, case or Lean credit and does not claim to restore every
historical runnable project.
