Publication trial preservation
==============================

The inventory records exact bytes of the L052 publication test checkout.
Its ordinary files comprise 1,632,947,130 bytes present in committed Git blobs,
12,529,205 bytes in the ignored working notes archive, four unique files
preserved here, and 2,605,472 bytes of disposable Lean build output.
All seventeen compiled Lean modules have corresponding Lean source files.
The two recorded relative symlinks remain reconstructible from the inventory.

The original .git entry was a symlink to the shared repository and was never
followed while inventorying or deleting the test checkout. That shared Git
store is protected separately. The four unique files are test configuration,
a catalogue snapshot and a rendered protocol; they confer no mathematical credit.

Decompress inventory.json.xz for the original names, SHA256 digests, Git blob
identities, archived note names and explicit compiler exclusions. The original
Git blobs are at commit f7c9fa7db33d5ad23ed35a475e95d232bff4e980.
