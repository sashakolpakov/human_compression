Inspect and verify
------------------

From the repository root::

    python3 -E -B -S october_corpus/research/intake/proof_methods/verify.py

This command checks the manifest and all 290 stored objects twice, including
preservation of every file in the earlier manifest of 273 retained files. It
executes no archived source and checks no matrix or permutation predicate.

``manifest.json`` maps 299 historical source paths to ordinary files under
``objects/``. An object's filename is its SHA256. The historical paths are
provenance labels; the verifier does not open them. For example, locate an
original ``PROOF.tex``, ``theory.tex`` or ``reuse_integer_only.json`` in the
manifest and read its corresponding object as text. All files are retained
without rewriting their original references or authority fields.

Scope and reproduction
----------------------

The earlier finite retention and independent byte audit are included, along
with the later selected-shard preparation and its independent actual audit.
These records establish the listed bytes and their stated review scopes.
They do not establish recursive preservation of every upstream input or
provide a portable command for all these historical calculations. Registered
upstream dependencies remain separate. The corpus reproduction guide gives
the existing portable mathematical entry points.

Do not execute an archived program by assuming that its historical absolute
paths exist in a clone. This is an evidence archive, not a replacement for
the portable reproduction packages or the completed manuscript proofs.
