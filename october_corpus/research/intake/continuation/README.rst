Continuing the unfinished treatments
===================================

These bundles preserve inputs, programs and existing certificates before local
working copies are removed. They add no mathematical results, case credit,
Lean verification or measured compression. Restore each selected bundle using
its own manifest and guide; old absolute paths and runtime permissions need
fresh admission before execution.

* matrix_certificates/: the current F004 source and retained references, the
  canonical model and job inventory, and the baseline certificate basis. The
  inventory has 239 members; the certificate archive has 45 distinct bodies
  for 102 references. The guides state the limits of this preservation audit.
* forest_and_census/: current F009 and L026 state and source references. All
  39 continuation banks are retained in the preceding progress archive; this
  supplement supplies the 59 additional bodies identified by the audit.
* sporadic_geometry/: selected Co2 model inputs, source and small records for
  future work. This is neither a full native Co2 proof nor the complete old
  wrapper environment. The published arithmetic retains its imported premises.

Complete member sizes and SHA256 digests accompany each compressed archive.
Existing source objects are identified by the preceding committed archive or
Git blob. Use copies when restoring logical aliases: do not introduce hardlinks
into inputs whose runtime guards require a single link.

Unpublished arguments and Lean source are retained separately in
../history/mathematical_notes/. Original manuscript access is recorded in
../maintenance/source_access.rst. Generated build products, unused solver traces
and obsolete execution copies are not prerequisites of the published checks.
