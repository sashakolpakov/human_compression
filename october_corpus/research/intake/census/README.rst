From the repository root, verify the new checkpoint's byte objects with::

  python3 -E -B october_corpus/research/intake/census/verify.py

Add ``--new-only`` to check only newly introduced objects, or ``--remote``
to stream the selected bodies from the immutable public commit. The reader
writes no downloaded files and executes no mathematical Source.

Byte verification establishes preservation, not mathematical truth. The
mathematical checks are the supplied strict checkers, with their exact
Source, input-state, control and runtime requirements. Operational records
retain absolute paths. A faithful replay must select the recorded input
edition and use fresh output paths; it must not replay ledger mutations
or treat discovery output as a verified certificate. Historical editions
of the mutable F004 pointer have separate frozen aliases. These archives
do not claim a portable replay on an arbitrary filesystem.
