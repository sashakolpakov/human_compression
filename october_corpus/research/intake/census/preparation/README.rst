Prepared argument and certificates
==================================

These files explain a proposed small certificate for an end generating
G2(11), using explicitly attributed subgroup classification. The
mathematical criterion has an independent static review. The operational
checker still lacks a completed independent Source review.

The checkpoint stores thirty untrusted candidate certificates and their
discovery records. No strict Original call or ledger adoption has been
made for these candidates. The current accepted count remains 777/807.

The accepted nongeneration proofs are in the separate ``proofs`` directory.
