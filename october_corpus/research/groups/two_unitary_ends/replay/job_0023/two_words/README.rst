Rechecking four adopted batches
================================

This standalone checker re-evaluates the original matrix words for four
previously adopted batches of intersection property failures in G2(11).
It uses files inside october_corpus only. Historical absolute paths serve
as declared identifiers; the checker never opens those paths.

The four actual runs passed for 434, 957, 955 and 749 distinct original
positions, respectively: 3,095 in total, representing 12,380 original
members. Their complete results, calls and resource guards are retained
in verification/. The earlier checker for 27 cases is unchanged.

From the repository root, run the following in a shell with Python 3.9
or later. Only the Python standard library is required.

.. code-block:: sh

   CORPUS="$(pwd)/october_corpus"
   REPLAY=research/groups/two_unitary_ends/replay/job_0023/two_words
   python3 -E -B -S "$CORPUS/$REPLAY/controls.py" \
     --self-sha256 c282dbb37c30c9d875045485ddbe2b68a3a7d9347c4fd405a8481d71c0979402 \
     --program "$CORPUS/$REPLAY/verify.py" 74b61864324a90577f1c7aede1ec0b0729c25ba2145dc9ba855932e3cefac2e5
   for batch in \
     434:29939c82aa04d2cab65f82d870c0f83efdc25fd95df09742f7dd1995e654af0f \
     957:0bd0770dfdd0f59ed2dd3d6ed107a8887fbc0a8bc35770378c2d592989350e30 \
     955:d8ed472c60c2c880bfb7ff8e355c2c753c5169b7a4092acf7028098962a4c4be \
     749:e034beb9afa073030cd73f029413c5b46784713bd45b1572c92e50905381ab4e
   do
     python3 -E -B -S "$CORPUS/$REPLAY/verify.py" \
       --corpus-root "$CORPUS" \
       --plan "$REPLAY/plans/batch_${batch%%:*}.json" \
       --plan-sha256 "${batch#*:}" \
       --self-sha256 74b61864324a90577f1c7aede1ec0b0729c25ba2145dc9ba855932e3cefac2e5
   done

Each run checks all four actual involutions and distant commutations,
then evaluates a word in each subgroup generated by three specified
involutions. It forms the sixth power of each word, checks that this is
nonidentity, and checks that its 37th power is identity. The retained theorem then proves failure of the
intersection property. The exact original faithful action, group model,
frame, orbit membership, Cayley normalization and subgroup classification
remain attributed imports; these runs do not reconstruct them.

The adapter and controls are by the prime theory audit agent; the
relative resolver and mathematical core are inherited from the earlier
checker. The complete source inverse, independent review and Root review
record that reuse. The file header records its status when the source was frozen;
verification/ contains the later actual runs.

These are fresh checks of existing certificates. They add no newly
settled position, completed manuscript, conjecture answer, Lean proof or
compression measurement. The separate 224 section certificates and 132
more recent literal word certificates require different replay interfaces.
