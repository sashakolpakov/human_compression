Supplied matrix obstructions for five original families over F11
================================================================

This directory contains a small, portable arithmetic check for 16,352 supplied
positive certificates among 16,414 indexed rows in five marked families. All
62 remaining rows are explicitly retained. A positive row has either a proper
generated matrix subgroup or a violation of a required intersection equality,
under the imported correspondence and group premises stated below.

The checker repeats the finite matrix calculations. It does not acquire the
original groups, generate the original domains or orbits, recognize the saved
model, or prove the subgroup classification. It makes no manuscript,
conjecture, formalization, whole-census or compression claim.

Run with Python 3.10 or later on Linux or macOS, from the repository root::

    python3 -I -B -S october_corpus/research/groups/shared_obstructions/check.py

Only the standard library and the two adjacent data files are used. Paths are
relative to the script, so a copied directory also works. The checker writes
one JSON receipt to stdout and creates no runtime files. Its own limits are
125 seconds, 128 MiB sampled peak RSS, 32 MiB of data reads and 400,000 matrix
products. These are checks of the running process, not kernel quotas or a
speed guarantee. An isolated copy passed the complete check in 2.61 seconds,
using 42,811,392 bytes sampled peak RSS and 344,495 matrix products. The
receipt is bundled as ``verification.json``; timings vary by machine.

``cache.u8`` has exactly 723,387 bytes. Catalogue index j, starting at one,
occupies bytes 49*(j-1) through 49*j-1. Those 49 unsigned bytes are the row-major
entries of a 7 by 7 matrix, each in {0,...,10}. There are 14,763 matrices.

``portabledata.json`` is ordinary JSON containing the two ambient matrices,
three fixed matrices for each job, every original orbit row, all supplied
positive records and the 62 unresolved positions. The fixed matrices are
stored in the original order [a,e,b]. The marked order used by the arithmetic
is [a,b,c,e], with c taken from the indicated catalogue representative.

An orbit row is [representative, orbit_size, point_stabilizer_order]. Its
original index is its one-based position in that job's list. A positive record
is [original_prefix, original_index, representative, tagged_witness]. An
unresolved record is [original_prefix, original_index, representative]. The
four supplied positive batches contribute 5,661, 9,940, 696 and 55 distinct
positions. The checker verifies that their union and the unresolved positions
are a disjoint partition of all 16,414 bundled indexed rows. A stored orbit
size or stabilizer order is an imported datum, not an orbit calculation
performed here.

The positive tags are 1,451 ``line``, 438 ``commutant``, 8,486 ``pair`` and
5,977 ``prime_end`` records. A missing witness is unresolved; an unsuccessful
search or a scheduling cursor is not a negative certificate. The final 62
records can be read directly in the JSON ``unresolved`` list. No search state
is required to interpret them.

Arithmetic and three elementary criteria
----------------------------------------

All calculations use integers reduced modulo 11. Matrices multiply in the
usual row-by-column convention; row vectors act on the right. Every cached
matrix and each fixed mark is checked to be a nonidentity involution. For
every indexed row, including unresolved rows, the distant commutations
ac=ca, ae=ea and be=eb are checked. Both ambient matrices are checked to be
invertible. These are literal matrix assertions; membership in the intended
original ambient group is one of the premises below.

Write H=<a,b,c,e> and let A be the intended ambient group. A candidate for a
regular rank-four marking of A must generate A and satisfy the intersection
property

    <r_i : i in J> intersect <r_i : i in K> = <r_i : i in J intersect K>

for every pair of index sets J,K, where r=(a,b,c,e). The subgroup generated by
the empty set is {I}. Each of the following elementary certificates is enough
to obstruct such a marking.

1. An invariant line moved by an ambient element.

   A line witness supplies a nonzero vector v, four signs lambda_i in {1,10},
   an ambient matrix t and coordinate indices u<v. The checker verifies all
   four identities v*r_i=lambda_i*v. Thus every mark and every word in the
   marks preserves the one-dimensional subspace L=span(v). It then computes
   w=v*t and checks v_u*w_v-v_v*w_u is nonzero. That minor proves w is not a
   scalar multiple of v, so t does not preserve L. Since t belongs to A,
   H is a proper subgroup of A. The marks cannot generate A.

2. A common commuting matrix which fails to commute with an ambient element.

   A commutant witness supplies an arbitrary 7 by 7 matrix X, an ambient
   matrix t and one matrix entry. It verifies X*r_i=r_i*X for every mark.
   Commuting with the generators implies commuting with their products and
   inverses, hence with H. At the specified entry it verifies X*t differs
   from t*X. Therefore t is not in H, although t is in A, and H is proper.
   X need not be invertible. Its displayed noncommutation is all that is
   needed; no commutant search or nullspace computation is repeated.

3. A forbidden intersection witnessed by two literal words.

   A pair witness gives a case and two descriptors (k,epsilon). For a pair
   (x,y), the descriptor means (x*y)^k*x^epsilon, with 0<=k<128 and
   epsilon in {0,1}. The checker evaluates exactly the supplied descriptors.
   In case0 the pairs are (a,b) and (b,c), and their equal value must be
   outside {I,b}. In case1 the pairs are (b,c) and (c,e), and the equal value
   must be outside {I,c}. In case2 the pairs are (a,b) and (c,e), and the
   equal value must be outside {I}. These contradict, respectively, the
   intersection equalities for index sets {0,1}/{1,2}, {1,2}/{2,3} and
   {0,1}/{2,3}. Since each common mark is a nonidentity involution, its
   one-generator subgroup is exactly {I,mark}. No enumeration, order
   minimality or exhaustion of either pair subgroup is needed.

The further prime-end criterion uses a borrowed classification theorem
---------------------------------------------------------------------

A ``prime_end`` record selects one end, either indices {0,1,2} or {1,2,3},
and supplies two literal words in that same end. Each word has at most 18
letters. The first word's fourteenth power Y is checked to satisfy Y!=I and
Y^19=I. The second word's sixth power Z is checked to satisfy Z!=I and Z^37=I.
As 19 and 37 are prime, these identities prove the exact orders of Y and Z.
The checker does not need the order of either original word.

The extra group-theoretic premise is that every subgroup of the intended
G2(11) containing elements of both orders 19 and 37 is the whole G2(11).
This is a corollary of the complete maximal-subgroup classification for the
split finite group G2(11), not a theorem proved by these matrix calculations.
The supplied source note uses P. B. Kleidman, “The maximal subgroups of the
Chevalley groups G2(q) with q odd, the Ree groups 2G2(q), and their
automorphism groups”, Journal of Algebra 117 (1988), 30–71. Its specialization
at q=11 lists all maximal subgroup types and checks that none has order
divisible by both primes. If a proper subgroup contained Y and Z, finiteness
would put it in a maximal subgroup, and Lagrange's theorem would contradict
that list. This use of the complete classification is explicitly imported.

Conditional on that theorem and the original ambient identification A=G2(11),
the selected three-mark end is A. It then contains the omitted nonidentity
mark. Its intersection with the subgroup of that omitted mark is not {I},
although the two index sets are disjoint. This contradicts the intersection
property. Both prime orders must occur in the same selected end; one order
in each of the two different ends would not justify this argument.

Imported premises and limits of the conclusion
----------------------------------------------

The package makes the following premises explicit rather than silently
promoting matrix calculations into an acquisition of the original objects.

* The raw cache and fixed matrices correspond to the original named Cayley
  catalogue and prefixes in the declared faithful F11 frame. The original
  model-to-matrix construction and normalization are imported. This checker
  does not reconstruct the original eight-dimensional Cayley operators or
  recheck that correspondence.
* Each job's indexed domain, representative labels and orbit list are the
  original acquired ones, with the advertised completeness. The partition
  check proves completeness relative to the bundled lists, not that those
  lists exhaust the original mathematical domain.
* Every mark belongs to the intended ambient original group A, the two
  ambient matrices belong to and generate A, and that original group is the
  split G2(11) required by the classification premise. These membership,
  generation and model-recognition facts are imported. Invertibility alone
  does not establish them.
* The faithful correspondence transports the word equalities, inequalities
  and subgroup statements back to the original objects. When orbit
  representatives are used to stand for other domain points, the original
  orbit action must act by automorphisms preserving the fixed marks. The
  listed obstructions are preserved by those automorphisms; simultaneous
  conjugation is a familiar case.
* For ``prime_end`` records only, the complete-classification corollary just
  stated is an additional imported premise.

Under these premises, each positive record obstructs the claimed marking of
the original ambient group. Without them, the receipt establishes only the
specified matrix arithmetic and the partition of the supplied lists. The
62 unresolved rows remain unresolved by this package. Even complete coverage
of these five supplied families would not by itself prove the whole F004
problem or a manuscript claim.
