Faithful packed keys
--------------------

Use zero-based labels and at most131072 points. For b in the class of a,

    key(b) = (beta^b : beta in B).

Each entry has exactly17 available bits. Entries are packed consecutively,
least significant bit first, with all final padding bits zero. The stride is
ceil(17*|B|/8), at most43 bytes. This encoding is injective on tuples. If two
class elements have the same key, their quotient fixes B pointwise; both are
in G, so faithfulness proves they are the same group element. A 64-bit FNV
hash selects a starting slot only. Every occupied lookup compares the entire
packed stride with memcmp; hash equality never proves element equality.

The table has 2^23 uint32 slots for the maximum domain. Empty is0; a tombstone
is UINT32_MAX; actual node IDs are1..N. All probes are bounded by the complete
table length. The load bound is strictly below one half. Tombstones preserve
old probe chains after interrupted insertions. Their possible cost is charged
to the operation/physical guard; no unbounded retry or silent table growth is
allowed. A fresh restart rebuilds from accepted keys and removes tombstones.

Factored words and exact orientation
------------------------------------

Node1 is a, with identity conjugator, parent0 and factor0. Every later node
stores an earlier parent and one positive authenticated factor f, naming

    g_i = g_parent * f,       b_i = a^(g_i).

The complete word is recovered through strictly decreasing parent IDs. The
core limits its length to8192 and checks every parent/factor. A length stop is
unpaid, not an assertion that the whole class has a short-word diameter.
For right actions, the reused direct-key identity is

    beta^(g^-1 a g) = ((beta/g)^a)^g.

The core's local word array is in reverse multiplication order. It applies
inverse factor maps in that order, applies a once, then applies forward maps
in reverse array order. Hence it computes exactly this tuple without forming
the full middle permutation. The inverse of every full factor is constructed
and checked from its actual bijection. The core also checks the full a is a
nonidentity involution. Actual membership in named G, base faithfulness and
endpoint generation/order are explicit authenticated input premises, not
inferred from these format checks.

Complete orbit transactions
----------------------------

For a proposed seed a^g, close under all supplied T generators using a queue
of at most256 node IDs. Every forward edge is evaluated by the exact formula
above and retained as its target ID. A target in an older committed interval
is refused. A new key is inserted once with its earlier queue parent and
factor; a repeated current-orbit key uses the existing target. The completed
queue is reachable from its seed by construction. Every generator edge is
inside the queue at exhaustion, so it is forward closed. In a finite
permutation action forward closure also gives inverse closure. It is therefore
exactly one T-orbit. Its size must divide the acquired |T|; divisibility alone
is not the orbit proof.

Only a whole closed orbit commits. On a stop/refusal after inserting new
nodes, pck_close makes all newly occupied hash slots tombstones, restores the
old count and clears the returned orbit. Existing node data and probe chains
are retained. Stale array bytes after the restored count are not accepted
nodes. An operation stop is sticky at its finite limit; the caller may still
serialize the last committed prefix using bounded read-only accessors. It
must not treat a failed call's zeroed orbit as mathematical work.

Supply seeds by a global queue of committed nodes and ambient G generators.
Start with a. Test each a^(g_i*s) and close a new T-orbit when absent. Each
new node has an actual G-word witness. The connected conjugacy Schreier graph
under generators of G eventually supplies every class member if all required
edge operations complete. Its at most N*d_G candidate transitions are not an
unbounded random dictionary. Together with at most N*d_T orbit edges, the
proposer has at most N*(d_G+d_T) candidate-key calls, apart from explicit
checkpoint/restart rechecking. Word cost is separately bounded by20 base
points,8192 factors and the finite operation guard. This is a finite bound,
not a runtime or short-diameter claim.

Coverage does not depend on trusting that seed algorithm: any disjoint closed
T-orbits containing N distinct actual conjugates exhaust the entire class.
This is exactly the borrowed mass argument, since |C_G(a)|*N=|G|. An earlier
stop never proves absence or completeness. In particular a checkpoint below
N has only its explicit complete-orbit coverage, not a census.

Saved verification and restart
------------------------------

Saved receives the node prefix, factor/base identity and all orbit records.
pck_check_append requires the sole first root, an earlier valid parent/factor,
the recomputed full key including zero padding, and a new distinct key. A
duplicate, including a repeat of the last inserted node, returns PCK_OLD and
must be refused by the caller. It never proposes a new word or performs an
orbit search. pck_check_orbit requires consecutive IDs, bounded size, every
actual supplied edge equality and directed reachability from the first node.
Its small graph traversal checks supplied edges; it does not discover class
elements. A disconnected union of closed orbits is rejected.

The future wire/caller must require orbit intervals to cover the entire node
prefix exactly once, in order, and compare every canonical header, scalar,
node, word field, edge, component byte and whole file digest. It must not use
native C struct bytes as a portable file format. Restore reconstructs the
dictionary by the same Saved append checks and checks every accepted orbit
before using an ambient queue cursor. It then records the exact last completed
ambient transition, with no half-orbit cursor advancement. A new manifest
extends the exact accepted node/orbit prefix and preserves every old manifest.
These I/O, canonical framing, atomic file commit and Root CAS wrappers remain
to be authored/reviewed; the present core has no hidden filesystem or CURRENT.
