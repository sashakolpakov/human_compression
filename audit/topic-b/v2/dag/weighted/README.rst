Topic B: exclusive text ownership and explanatory proof costs
=============================================================

This author packet assigns every selected extracted character in the eight
available complete PDFs to exactly one owner. It uses the accepted Topic B
measurement boundary and independently accepted logical graph v2. Its own
semantic partition and owner interfaces still require independent review.
No graph factor, source credit or solved-question credit is introduced.

The three measured source PDFs and all five new papers are completely
charged. N001 has documentary graph nodes but no original-PDF cost. Neither
its browser representation nor a zero value is substituted for that PDF.
Expanded outside proofs and unmeasured graphical content also remain unknown.
The already accepted overall symbolic comparison and conditional application
factors are unchanged.

There are 217 disjoint spans and 214 owners. Eighty complete-document metric
cells are conserved exactly: five length units under NFC and NFKC for the
adopted calibrated selected text. All 2,140 owner cells use whole-document
normalization and tokenization. A token or collapsed whitespace run belongs
to the owner of its first character. Normalization across an ownership
boundary is checked rather than assumed. Exact raw positions, physical
pages and owned-text hashes identify every span without exporting its text.

Named theorem parents and substantive branches refer to unions of those
owners. A branch includes the shared full parent theorem statement when
present. These displayed costs can overlap: adding boxes is not a total.
Every closure uses a union of owner IDs, so no passage is charged twice.
Retained-input statement text is charged where it occurs, while the expanded
external proof cost stays null. The whole common theory remains paid in the
complete-topic comparison even when a particular explanatory route uses only
part of it.

partition.json records context, references and excluded source material too.
The 61 owners outside the selected logical interfaces are listed explicitly;
they are fully present in each complete-document total. Every substantive
new proof owner appears in a logical interface. A selected prerequisite
closure is neither a whole-paper denominator nor a minimum possible proof.
Source corrections and unequal graph granularity remain as in the accepted
logical packet; there is no raw-node-count ratio.

Reproduce in a fresh directory, using the bound private sources and pypdf
6.13.0::

  python3 -B -O author.py --study-root PRIVATE_STUDY --out FRESH_DIRECTORY
  python3 -B -O check.py --packet FRESH_DIRECTORY \
    --study-root PRIVATE_STUDY --out FRESH_REPORT_JSON

The checker verifies all eighty document cells, owner allocation, page and
text bindings, thirty fixed source-clause routes, four application routes,
complete CSV data and twelve corruption controls. It is an author
consistency check, not independent semantic review. The allocator reuses the
accepted Topic A algorithm, without importing any Topic A cost or sharing
cost across topics. No primary text, source PDF or source raster is exported.
