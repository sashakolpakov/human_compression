Reproduction
------------

Use Python with pypdf 6.13.0 and fontTools 4.63.0. Set the two roots to the
locally supplied scientific corpus and public repository. The output path
must not exist. From this exported packet::

  /Users/sasha/.venvs/global/bin/python -B -O check.py \
    --sources-root /Users/sasha/medusa/research/leemans \
    --public-root /Users/sasha/medusa/math_compression \
    --out /private/tmp/F005_input_new_replay --render \
    --xelatex /opt/homebrew/bin/xelatex

The replay checks all 180 PDF and 70 raw-file cells, exact complete input
hashes, the scientific acceptance, all 40 input controls, and whole-program
inclusion. With --render it rebuilds the two-page reader and both complete
code appendices in isolated directories and compares all nine page texts.

  /Users/sasha/.venvs/global/bin/python -B font_view.py \
    --sources-root /Users/sasha/medusa/research/leemans \
    --public-root /Users/sasha/medusa/math_compression \
