Co2 orbit certificate: validation records
========================================

The admission binds the proof, canonical manifest, checker, independent reviews
and two actual arithmetic replays. The second replay used a separate directory
containing only the 52 canonical files. Both produced the same complete list
of 3,627 excluded row keys.

The checker regenerates the certificates from data/sporadic_rank3/co2_nonfree;
none of the files in this audit directory is an input to the calculation.
Machine paths and tool identifiers in copied records document the original
executions. They are not paths that a new checkout must provide.

The named group, centralizer identities and complete orbit partition remain
imported premises. The 21,063 full-size rows and the original manuscript L026
remain unfinished. See admission.json for the precise scope.
