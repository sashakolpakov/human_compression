============================================

source PDFs, the common paper, six applications and complete code appendix to

Files
-----

``partition.json`` contains half-open codepoint intervals, exact span hashes,
raw-extraction bounds, physical pages and ownership categories. No primary
text is redistributed. The partition has 341 spans and 337 distinct owners;
these counts include context, definitions, tables and references and are not
counts of comparable proofs.

``weights.json`` contains all five adopted metrics in both NFC and NFKC,
per-owner costs, category totals, nonadditive named-theorem rollups and the
recorded dependency closures. ``owner_costs.csv`` is the same leaf-cost data
in a sortable table. Every whole-document metric agrees with the independently
accepted measurement: 140 cells across 14 documents and 164 physical pages.

Named statements and substantive proof branches have separate ownership leaves
where a theorem bundles multiple arguments. A theorem rollup is a set of leaf
IDs, not another charged item. Union those IDs before summing. Each global
token and collapsed whitespace run belongs to its starting owner; independently
trimming each substring would give different, nonadditive counts. Normalization
is checked to commute with the chosen boundaries.

The four raw programs and their appendix are alternative representations. This
coordinate charges the full appendix once, including its wrapper. All four
computational nodes point to that one shared owner. Full raw-program inclusion
is verified. Their closure is shared between A5 and A6, never charged twice in
the whole-topic denominator.

Limits of a dependency subtotal
------------------------------

Every selected character is charged in the whole-document totals, including
introductions, retained statements, auxiliary source material and references.
Some named units contain short attached connective prose; the exact boundaries
are available for review. A documentary closure subtotal is not a claim that
the closure is minimal or that it includes every possible definitional premise.
The other paid text in its documents is listed explicitly. Source argument
qualifications, including corrected or unsupported clauses, remain attached.

External theorem proofs, unextracted scientific raster labels and diagram
structure have unknown cost, recorded as null. They are never assigned zero.
In particular, the known L035 image issues on pages 9, 10, 12 and 22 remain.
Neither raw node counts nor closure subtotals are presented as compression
ratios. Whole-paper comparisons remain the separate adopted measurement.

Replay
------

Use Python with pypdf 6.13.0 and the explicitly bound private study tree::

    python3 -B -O check.py --study-root /path/to/private/study --out /fresh/report.json

The checker verifies all bound inputs, extraction, unique ownership, atomic
weights, physical-page locators, CSV data, retained unknowns, all contract
closures and full program inclusion. Ten mutations test gaps, overlaps,
incorrect hashes, zeroed unknown costs, double charges and weight corruption.
It does not prove mathematical correctness of a dependency edge. That review
is separately bound. ``author.py`` is the deterministic construction script;
run it only on a working copy, preserving this frozen edition.
