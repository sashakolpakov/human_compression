Verifier migration
------------------

includes the old README. Keeping a few old phrases is therefore insufficient.
The proposed new ``check_programme51_documentation_history`` runs that unchanged
guard under a read-only overlay of exactly three saved files: README.rst and
audit/protocol.tex/pdf. All other current files remain visible. The separate
new ``check_current_documentation`` verifies the new current documents.

Append the two definitions in proposed/integration/new_guard_functions.py.
In main only, replace ``programme51 = check_programme51()`` by the historical
overlay call, then call the new current-document guard. No existing non-main
function changes. The private stage verifies all 128 prior ASTs exactly and
adds only those two functions. Both build_papers.py and check_programme51.py
remain byte-identical. integration_plan.json gives the exact steps.

The new guard checks the accepted programme and table bindings, the current
51/54/1/55 partition, all nineteen rows, symmetric manuscript/software wording,
unknown costs, local links, exact rendered page text and preserved historical
functions. It does not replace scientific or numerical verification.
