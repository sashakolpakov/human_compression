LCD and programme50 publication proposal
=======================================

This private author proposal preserves every accepted scientific and numerical
byte. Root is the sole public writer and issues the actual publication
admissions. All scientific/input/numerical reviews are accepted; this proposal
is not its own public admission. L050 and F017 are the only proposed additional
originals. L121 is excluded.

assembly_map.json lists exact copies of thirteen complete frozen packets,
including their manifests. catalogue_rows.json declares the three complete
scientific papers, literal titles, full TeX closures and actual compilers.
Every row explicitly routes the conservative whole topic-wide required and
optional collection; an empty program list is not used to conceal premises.
raw_routes.json maps all 127 occurrences of 102 unique contents. Identical
copies remain in their original layouts for replay, while the accepted cost
inventory deduplicates whole contents only. No scientific programs are rerun
by this assembly.

Proposed placement of this packet is audit/topic-lcd/v1/publication_plan.
PUBLICATION.rst can be copied to papers/topic-lcd/v1/PUBLICATION.rst.
The root admission and measurement admission drafts are exact, concrete
review material; their status explicitly requires root publication acceptance.

Fresh private stage and authoritative-engine rebuild::

  python -B -O stage.py --study-root STUDY --public-root REPO --out FRESH --render

Complete public-file input recount, with separately supplied originals::

  python -B -O recount_public.py --public-root STAGED_OR_PUBLIC_REPO \
    --sources-root ORIGINALS --out FRESH --render --xelatex xelatex

ORIGINALS contains the exact accepted catalogue_L050.pdf and
lcd_followup2018.pdf. The adapter creates a private logical path tree, then
runs the immutable adopted input checker. It never exports these primary
assets or runs a large scientific enumeration.

The compiler proposal consists of build_papers.py, its literal diff and
compiler_controls.py. Only the two allowed declared engines are selectable;
old rows default to XeLaTeX, and all four old non-main helper ASTs remain exact.
All 121 previous snapshot non-main function ASTs are recorded in the baseline.

Registration generation after root creates actual admissions::

  python -B -O register.py --public-root REPO --payload-root STAGED_REPO --out FRESH

During private preparation only, --proposed-admissions selects the explicitly
unadopted templates. check_programme50.py needs --allow-proposed for that mode.
All 104 other original records, all 84 old current-catalogue rows and every
prior source-access record remain unchanged. Exactly three scientific rows
are appended; there is no invented printed-program appendix.

check_lcd_publication.py, check_programme50.py and snapshot_additions.py are
narrow proposed public checks. Root should preserve old verifier functions and
run historical pointer checks against the exact saved previous snapshots,
using a read-only overlay rather than editing those functions. The root must
also bind its final programme registration to overview v16 independently of
the author overview's exact expected 50/56/106/55 partition.

The overview is a separate frozen author proposal at
corpus106_overview50_candidate. It preserves all eighteen prior topic objects,
48 individual records and 66 fractions; LCD adds three for 69 total and 157
actual plotted bars. The proposed overview route is audit/overview/v16/packet.
No public pointer is changed by these scripts.
