Programme for all 161 originals
===============================

Every indexed original remains a target. This inventory replaces the old
bounded intake policy as a programme description; it changes no frozen
scientific admission, question record or measured factor.

The snapshot has 104 accessible originals: 100 PDFs and four complete
non-PDF representations. There are 27 admitted principal contracts, 77
accessible originals pending complete recovery, and 57 complete-body retrieval
targets. N006 and N007 explain the old 102/current 104 access discrepancy.
N001 and L108 are accessible complete authored renderings despite missing PDFs.
L022 is a complete editorial; it stays in the original count without an
invented mathematical theorem. N005 is complete primary arXiv HTML.

Start with summary.json and prioritized_batches.json. inventory.csv is the
flat 161-row table; inventory.json gives exact source hashes, usable edition
representations, original attribution, prior proof/admission evidence,
principal targets, measurement status and the next obligation. inventory.rst
is the complete readable programme. All 134 originals outside the existing
27 admissions occur exactly once in the suggested execution batches.

Limits
------

This is an authored evidence reconciliation, not an independent acceptance
of every old component or a new review of all 161 proofs. Bounded new source
readings are recorded in source_reading_annotations.json. Machine-located
numbered statements are explicitly marked as candidates. Unread principal
statements stay pending; no theorem is invented from a title. Existing
components, conditional results, generic encodings, author candidates and
admitted principal contracts have separate statuses. Later reviews and
admissions must be additive to this frozen snapshot.

The original identity list comes from the immutable 161-entry registry.
No new title is introduced. No genuine duplicate original ID has been
confirmed. Several misleading catalogue PDF filenames actually contain
HTML errors or a different original; those artifacts never confer access
to the intended source. L007/L127 and L063/L064 are not merged.

All source-specific complete Lean obligations remain separate from existing
scoped declarations. No new source credit, question credit or factor is
computed. Missing source graphics, historical computations and external
proof costs are not assigned zero. The old N001/L108 PDF-only measurements
remain immutable; root is preparing an explicit rendering sensitivity.

Replay
------

With the separately retained private study and public repository:

  python -B -O check.py --study /path/to/study --public /path/to/repo --out /fresh/output

This checks all 161 IDs, all 695 exact evidence bindings, CSV agreement,
complete batch coverage and 13 deliberate corruptions. It is a structural
and evidence check, not a proof verifier. It requires the separately retained
primary source artifacts; they are not exported in this packet.

To reconstruct the authored inventory in a new directory, run build.py with
--study, --public and --out, then finish.py --out. The builder uses pypdf and
records the current public commit, so a later repository state can naturally
produce a new snapshot. Source PDF extraction warnings are not suppressed;
glyph-name and diagram-heavy originals need visual reading before exact
statement/proof transcription. No complete-text measurement is made here.

The private_sources directory contains the locally retained original N005
HTML, is deliberately absent from the export manifest, and must not be copied
as part of a public inventory. Only scripts, metadata, counts and paraphrased
target descriptions are exported.
