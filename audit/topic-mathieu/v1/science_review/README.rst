Independent review of the M22 census and corrected tables
========================================================

This packet accepts the specified written and computational recovery of L073.
It preserves all source-row discrepancies and does not claim recovery of
unavailable historical geo[] numbering. The forty-eight-page predecessor is
used only at the nine recorded physical pages. No Lean or ratio is claimed.

The independent checker imports no author program. It checks actual group
orbit sets, all source-row candidate sets and an independent binary-code
completion enumeration. The fresh author traversal supplies the exhaustive
census, whose written algorithm and proof were reviewed separately.

Run with Python, pypdf and GAP with TomLib available::

  python3 -B -O check.py --packet ../corpus161_L073_recovery \
    --primary ../sources/catalogue_L073.pdf --out /fresh/output

Omit --primary for a source-free replay of the already bound row records.
Source PDFs and all page rasters remain private and are not exported here.
