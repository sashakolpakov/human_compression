Topic F: proposed measurement inputs
===================================

This packet fixes reproducible input counts for the accepted Topic F proof
edition. It does not calculate or admit a compression factor. Independent review
of these extraction and calibration boundaries is still required.

Complete papers and programs
----------------------------

The source is the complete 12-page arXiv:2407.10388v1 manuscript of 15 July 2024,
including its title, abstract, bibliography and author contacts. The comparison
pays the complete four-page common paper and five-page application. The whole
four-page appendix contains all three validation programs. Those programs test
the proofs; no finite result is a premise of the uniform written arguments.
Their whole raw files provide an alternative representation, never an addition
to the printed appendix. Both complete archival operational drivers are measured
separately. The one Lean file, with five previously accepted scoped declarations,
is also separate. No complete source theorem is claimed to be formalized.

The first eventual comparison is the whole source divided by the whole common
paper plus application. Including the complete validation program is a separate
comparison. The source/application comparison is conditional on acquiring the
whole common paper and validation package. Overlap with other topics never
reduces Topic F's common-paper cost. No comparison is computed here.

The accepted contract has 25 source rows. It includes the explicit correction to
the marking printed in source Theorem 1.2, and does not assert recovery of every
auxiliary statement or of the historical small-group statistical census. The
source is counted as printed, without applying the mathematical correction to
its text. The Cunningham--Pellicer tightness classification remains an external
input, with the exact previously read theorem, hypotheses and missing local
full-text cost recorded. Missing external or graphic costs are unknown, not zero.

Extraction and visible glyphs
-----------------------------

The replay uses pypdf 6.13.0 and fontTools 4.63.0. It counts five units under NFC
and NFKC for three variants: all untrimmed extracted text, text with only exact
running furniture removed, and that same selection after visible glyph repair.
All physical pages remain included. Hyphenation, generated whitespace, printed
code continuation marks and mathematical layout order remain unchanged.

The calibration binds 95 actual glyph events: 16 mathematical alphabet glyphs,
78 tall square-bracket pieces and one normality sign whose extracted character
points in the opposite direction from the embedded outline. Each event records
its original encoded byte, embedded font, glyph name, page, offset and context
hash. Every one of the source's 25,574 nonspace extracted characters is aligned
to an original text byte; all 595 encoded glyph classes and six actual banner
spaces are inventoried. Normality-sign repair concerns visible glyph identity,
not a correction to the source mathematics. All raw sensitivities are retained.

All 25 PDF pages were visually inspected. The source has 43 one-pixel inline
images used as rules, overlines and other strokes, including the large matrix
table on page 8. Extractable matrix and table labels are counted, but extracted
text does not measure their two-dimensional placement or graphic construction.
There is no OCR, source-image redistribution or claim of complete visible-text
measurement. The graphics cost remains unknown.

Portable replay
---------------

From a copy containing exactly the exported packet files::

  /Users/sasha/.venvs/global/bin/python -B -O extract_inputs.py \
    --study-root /Users/sasha/medusa/research/leemans \
    --out /fresh/absolute/directory

The study root supplies the already acquired private primary PDF and exact
accepted Topic F packets. The output is metadata and counts, never primary text.
Fifteen controls reject omitted programs/drivers/formal declarations, false role
changes, zeroed unknown costs, missing/wrong font-event repairs, a reversed sign,
a body-only source selection and invented furniture. To inspect actual embedded
outlines privately, run font_view.py with --study-root and a fresh --out PNG.
That PNG is not a distributable packet artifact.

Publication is pending at the fixed input boundary. An eventual public mapping
must establish byte identity to these exact accepted PDFs; this packet does not
invent a current public path or silently substitute a later edition. All
scientific author and independent-review freezes remain unchanged.
