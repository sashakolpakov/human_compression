Chamber publication integration review
======================================

This review accepts the root-authored public integration of the already
reviewed Chamber papers. It adds no mathematical, source, question or
numerical credit. The integration reviewer also authored the science;
scientific acceptance is supplied by the distinct review of
``enumeration_review`` and the separate root adoption, both preserved here.

The checker compares the exact candidate and copied manifests, all earlier
verifier functions and main calls, catalogue inputs, links and publication
scope. It runs the documented public binding command and the new guard,
then rejects 24 altered records and three undeclared additions. File hashes
remain enabled during the parsed-record controls. No GAP or Lean proof run,
primary extraction or independent re-adjudication of the mathematics is
claimed. The guard does repeat the accepted small Python interface models.

Replay from any working directory, with an unused output path::

  python3 -B -O check_integration.py \
    --repo /path/to/human_compression \
    --study /path/to/research/leemans \
    --out /tmp/chamber-publication-review-fresh.json

The study directory supplies the fixed candidate and three original frozen
packets. The checker writes only its requested report and a fresh temporary
binding directory, never the public repository. It accepts only the exact
candidate change set and its eleven explicitly named later paths. This is a
publication checkpoint; unrelated later edits need their own review.

``review.json`` states the conclusions and authorship limits.
``candidate_binding.json`` pins every reviewed public byte.
``integration_result.json`` records the exact positive checks and controls.
``visual_review.json`` records independent viewing of all seven protocol
pages. The scientific PDFs are byte-identical to those accepted separately.
``whitespace_review.json`` lists 243 preserved diagnostics in six frozen
author files; the mutable publication files pass. No blanket whitespace-pass
claim is made.
