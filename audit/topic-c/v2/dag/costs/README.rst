Topic C: proof passages, dependencies and costs
=============================================

This is a proposed ownership and reader layer over independently accepted
mathematics and complete-document measurements.  It does not independently
approve its own passage boundaries.  The original logical packets, scientific
papers, measurements and reviews remain unchanged.

Read ``reader.pdf`` first.  ``explorer.html`` is self-contained and works
offline; select a complete application or one of the forty fixed clauses,
then the historical or current route.  ``default_graph.pdf`` is a static C4
overview, not a browser screenshot.  Source citations and exact proof locations
remain attached to graph nodes.  Primary PDFs and their complete text are not
exported here.  Original L108 PDF cost remains unknown.

The first comparison is the complete written topic,
``(x + 60,256) / 71,277``.  The required-program-inclusive coordinate is
``(x + 60,256) / 80,076``.  The complete raw programs give the alternative
denominator 79,600; they are not charged in addition to the printed appendix.
The four conditional application comparisons prepay the WHOLE common theory
and BOTH complete programs.  Their denominators are complete applications,
including context and references.  These are already admitted document
figures, not new factors inferred from the graph.

Files and scope
---------------

``boundaries.py`` declares semantic passage starts against the pinned PDF
extraction.  ``partition.json`` assigns each character to exactly one owner.
Title, definitions, context, references, appendix wrapper and excluded
furniture have owners.  ``weights.json`` and ``owner_costs.csv`` supply all
thirty coordinates: three admitted text policies, NFC/NFKC, and five length
metrics.  The allocator assigns a whole token or collapsed whitespace run to
the owner of its first character and checks normalization across boundaries.
The raw-program alternative supplies ten coordinates per full file.

Graph parents, statements, branches and program aliases may share owners.
Route totals take their union before summing; box costs must not be added.
The 199 owners and 156 mathematical/documentary graph nodes are different
objects.  No node-count factor is defined.  Smaller route subtotals are not
complete-paper denominators or minimal proofs.  Unknown outside proofs and
graphics remain null, even when a known local text subtotal is available.

``acquisition.json`` acquires all of U_C, then the complete program appendix,
then C1, C2, C3, C4.  Each application pays all its local owners, including
context absent from a selected proof route.  The already-paid prerequisite
union is reported without subtracting it again.  No costs are shared across
topics.  The missing historical source prevents a full numerical source
cumulative curve.

Reproduction
------------

The full cost replay needs the declared private study-root layout and original
PDFs, Python with pypdf 6.13.0, and Node.js.  The reader itself needs no server.
Run from this packet directory and use an output path that does not exist::

  python3 -B -O run.py \
    --study-root /path/to/research/leemans --out /fresh/replay

Add ``--render`` to build the two-page reader and static graph; this also needs
matplotlib, XeLaTeX and STIXGeneral.  ``--node`` and ``--xelatex`` select the
executables.  The runner checks all frozen exports, exact JSON/CSV/HTML/SVG
regeneration, complete-document conservation, forty paired interfaces, 85
output unions, acquisition and deliberate corruptions.  PDF reproduction
compares complete page text, not timestamp-dependent PDF bytes.

For incremental review, ``check.py`` checks ownership and ``check_reader.py``
checks the derived reader without running TeX.  ``test_explorer.js`` exercises
all 90 historical/current route views and all thirty coordinates in a
deterministic DOM harness.  This is not a real-browser layout test.

The proposed public HTML location is
``audit/topic-c/v2/dag/costs/explorer.html``; its current-proof PDF links use
that exact five-level depth.  Changing the publication layout requires a
separate routing adapter.  No public files have been edited by this packet.

Review boundaries
-----------------

Logical v2 and its independent review fix all mathematical arrows and source
qualifications.  The forty clauses include corrections, retained inputs and
two excluded auxiliary assertions, not forty claimed new theorems.  The
separate F014/earlier-polygon comparison stays outside those forty clauses.
The existing sixteen Lean declarations verify specified components, not complete
source applications.  This packet adds no formal theorem, source credit,
question credit, or historical-priority claim.  Independent passage/interface
and reader review is required before admission.
