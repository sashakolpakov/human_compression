Publication boundary and replay adaptation
==========================================

This is a private, concrete proposal for a bounded correction. The root
agent must inspect it and supply the component publication gate. The
proposal assigns no whole-original credit and does not change public files.

The four complete immutable packets are copied under proof/,
independent_review/, common/ and common_review/. Their original manifests
and all declared exports are byte-identical. They include both complete
four-page manuscripts, all arithmetic code and exact output, the source
table, the full maximal-class contribution ledger, the distinct 574-cell
class-constant audit, and the common component's independent review.

The transport contains 226 logical records. All mathematical manuscripts,
programs, finite evidence and review records needed here have public bytes.
Ten source-paper or source-image records are hash-only. Another 117 records
identify historical installed GAP/CTblLib software and data; they are
explicit external prerequisites rather than private proof files. The
exact integer character vectors extracted from those tables are public,
and fresh GAP output must reproduce them byte-for-byte. No claim is made
that hash checking proves the external maximal-subgroup classification or
the character-table group identifications.

The L071 orbit proof is retained in full for method attribution. Its census
is not a premise: the common stabilizer theorem is proved directly. The
historical N006 model likewise supplies no generating-pair or census claim
here. These roles are explicit in the frozen common dependencies and the
transport; the package does not silently import either numerical census.

The top-level public check.py is a new, explicit operational wrapper.
It does not rewrite any accepted program at runtime. It verifies all four
frozen manifests and their complete direct dependency routes, substituting
the declared public transport for historical absolute-path checks. It
then runs the unchanged GAP vector/control programs, the unchanged
independent class-constant program, and both unchanged common GAP programs.
The two frozen common programs used text=True in their accepted checker,
so their comparison applies the same universal newline translation; raw
stdout is retained separately. The other three output contracts stay raw
byte comparisons. The first private replay stopped at this newline-contract
difference, before acceptance, and its raw evidence remains preserved.
It evaluates the unchanged bounds.py directly and compares the independent
integer ledger. GAP and pdflatex are selected from the public environment
instead of the original Homebrew path. Native text is compared with the
accepted PDFs. Optimized Python is rejected before output, and the child
environment clears PYTHONOPTIMIZE and disables Python bytecode writes.

The wrapper adds thirteen malformed scope controls. They reject ordinary
recovery or terminal-refutation credit, a handled-original increment,
whole-paper completion, a changed counting convention, treating the lower
bound as exact, removing L046 from pending, dropping the 116 remaining
exact cells, a false factor, or new question/Lean credit.

The precise proposed catalogue changes are in catalogue_patch_plan.json.
They preserve all existing original-disposition sets and the counts
77 recovered, one terminal F003 refutation, 78 handled and 27 pending.
Only L046's evidence, verified edition and next obligation need change in
a new immutable catalogue edition. Other originals and all measurement
catalogues stay unchanged. A separate bounded-correction index should
link this result without adding it to the recovered-original or terminal
principal-refutation lists.

Publication requires the root's operational inspection, exact scope and
unchanged-count registration guard, historical snapshot checks and full
repository verification. No public integration, commit or push is performed
by this proposal. The root can revise documentation and registration before
its final gate; the frozen scientific packets remain immutable.
