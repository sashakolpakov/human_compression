Nineteen topics and forty-three originals
========================================

The `six-page comparison <packet/summary.pdf>`_ lists all nineteen topics,
their complete manuscript costs and all forty-three conditional application
factors. The active catalogue has 106 accessible originals: 43 have admitted
principal-result recoveries with measurements, and 63 remain pending.
The 55 unavailable originals stay archived outside this programme.

For a topic with common theory U and applications A_i, the written factor is
sum c(L_i) / (c(U) + sum c(A_i)). After acquiring the common theory and
declared retained premises, an application's factor is c(L_i) / c(A_i).
Every topic pays its own whole common theory. Overlap with another topic
does not reduce this cost. The figures measure the stated complete texts,
not a minimum proof complexity.

The `topic table <packet/topics.csv>`_ contains all nineteen whole-topic
factors; the `application table <packet/applications.csv>`_ contains all
forty-three individual factors. The `whole-topic graph <packet/whole_topics.svg>`_
and the two application graphs (`first 21 <packet/conditional_1.svg>`_;
`remaining 22 <packet/conditional_2.svg>`_) show all actual source, common
and application costs. PDF versions are beside the SVGs.

Validation programs must be counted on both sides or excluded on both sides.
These tables exclude separate software from both manuscript totals. The
`program inventory <packet/program_inventory.csv>`_ preserves the measured
replacement costs and each declared role. Comparable source software costs
are unknown, so there is no software-inclusive compression factor. Programs
or data needed by a proof remain required; the written factors do not measure
the complete cost of such executable proofs. Printed validation listings
have been screened for expanded F, but that screening is not claimed for
every older topic.

This edition adds L007 to F. L014 remains one already counted original;
the other eighteen topics keep their exact manuscript costs. F's complete
raw-text factor is 69,825 / 43,274 = 1.613555483662. Its source boundary for
L014 differs from the former selected-text coordinate; this difference
is not credited as a mathematical saving. The `F papers
<../../../papers/topic-f/v3/README.rst>`_ state the source corrections,
retained external theorems and partial Lean coverage.

The distinct `review <independent_review/review.json>`_ checks all 62 exact
fractions, all 81 CSV and PDF table rows, all 182 SVG and PDF bars, and the
104 untouched records in the complete active catalogue. All six reader
pages were inspected and 24 deliberate corruptions were rejected. It
reviews this consolidation using separately accepted mathematical and
numerical inputs; it does not repeat their proof review.

The `admission <admission.json>`_ binds the accepted author packet,
independent review, programme counts and source registration. Earlier
editions remain preserved. No solved-conjecture or formalization credit is
created by this numerical overview.
