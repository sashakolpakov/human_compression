Reproduction
------------

Use Python with pypdf and matplotlib; the author environment used Python 3.14.6,
pypdf 6.13.0, matplotlib 3.10.9 and numpy 2.4.4. A full reader build also needs
XeLaTeX with the fonts named in summary.tex. From this directory::

  python -B -O build.py --out /fresh/overview36 --render
  python -B -O check.py --packet /fresh/overview36 --out /fresh/check.json

To check the frozen packet without rebuilding::

  python -B -O check.py --out /fresh/check.json

The optional --public-root /path/to/math_compression additionally checks the
four old records against the exact committed baseline via git show. It does
not assume that the baseline is the current HEAD. All required numerical inputs
are copied and hash-bound under inputs/, so the default replay requires no
private study, primary PDF or public checkout. Output paths must not exist.
No GAP, Lean, extraction or mathematical proof is rerun.

The checker compares all 13 unchanged topic objects, complete exact rational
records and CSV/TeX output. It checks 142 cost rectangles in each of the actual
SVG and PDF figure sets, all six reader pages and 16 deliberate corruptions.
The copied-packet replay records regenerated JSON/CSV/SVG/TeX equality and
per-page PDF text equality. PDF container metadata need not be byte-identical.
