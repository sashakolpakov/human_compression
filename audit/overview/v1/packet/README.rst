Ten topics: complete papers and conditional applications
=======================================================

This is a consolidation of accepted numerical inputs, not a new mathematical
admission. The five-page ``summary.pdf`` gives complete source, common-theory
and application costs for ten topics and 27 distinct original manuscripts.
It also gives every conditional source/application factor and the complete
program alternatives. The later accepted F015 and L028 contracts await their
own measurements and are outside this fixed numerical baseline.

The primary unit is NFC characters without whitespace. Eight rows preserve
their accepted selected and calibrated PDF representation. B and C instead
use the separately reviewed literal N001/L108 renderings together with raw,
untrimmed PDF text for every other document on both sides. Earlier unknown
PDF coordinates are not overwritten. No pooled cross-topic factor is formed.
All full common theories are charged independently, with no discount for
overlap between topics. Unknown outside proofs, historical software, full
graphic information and end-to-end formalization costs remain unknown.

Evidence and roles
------------------

``inputs.json`` pins twenty admissions/results/review manifests. Public
measurement admissions supply A, D, E, Affine, F, G and Representation. The
separate B/C arithmetic packet is bound to its independent review; Chamber
is bound to the distinct root numerical acceptance. The compiler of this
overview authored some earlier scientific/input material and the Chamber
numerical packet, and independently reviewed the B/C arithmetic. Those prior
roles are not presented as independent review of this new consolidation.
Root will independently review this author packet before publication.

``results.json`` retains exact fractions and representation labels;
``topics.csv`` and ``applications.csv`` are convenient tables. E1--E3 are
display aliases of New_A1--New_A3. The graphs show full manuscript text costs,
not theorem counts. All existing source corrections, outside inputs and
excluded ancillary assertions remain governed by the earlier scientific
admissions. No original source text is exported here.

Replay
------

Python requires pypdf and matplotlib. The reader uses XeLaTeX and STIXGeneral.
The builder accepts ``--public-root``, ``--study-root`` and an optional
``--locations`` JSON mapping from input keys to exact relocated files; all
twenty byte bindings still apply. Use a fresh output directory::

  MPLCONFIGDIR=/private/tmp/summary-mpl python -B -O build.py --out /private/tmp/summary-replay --pdf-graphs
  cd /private/tmp/summary-replay
  xelatex -interaction=nonstopmode -halt-on-error summary.tex
  xelatex -interaction=nonstopmode -halt-on-error summary.tex
  python -B -O /path/to/this/packet/check.py --packet /private/tmp/summary-replay --out /private/tmp/summary-check.json

The author checker validates 57 exact comparisons, both CSVs, all 84 actual
SVG bars and all 84 PDF polygons, the complete generated TeX and five reader
pages. Twenty-two controls reject missing costs, false prepayment, unknown
costs turned into zero, wrong representations, duplicate/missing originals,
new credits and distorted or deleted plot geometry. These are author
controls, not a substitute for independent review. No source extraction,
GAP computation or Lean proof is rerun by this consolidation.

The fresh author replay reproduces eight generated files byte for byte and
all five reader pages text for text. The final XeLaTeX render has no recorded
overflow, missing-glyph or font-substitution diagnostic. All five final pages
were visually inspected. No interactive-browser claim is made.
