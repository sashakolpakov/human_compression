not remeasure a document, calculate a new factor, change a scientific admission,
or edit the public repository. All old observations remain available under
inputs/ and in separately named historical columns.

matched code boundary. Old overview/v10 charts are historical and require this
qualification; they are not unqualified current charts.

Optional validation must be included on both sides or excluded on both sides.
The same mismatch cannot be justified by labeling an executable listing required.
Written mathematics, algorithm prose, finite presentations and data tables are
not automatically removable program listings. No source section is removed here.
All software-inclusive/optional-validation factors remain null; unknown original
software, retained proof and graphic costs remain unknown, not zero.

Every topic pays its own whole common theory once. Conditional comparisons assume
that whole theory and actual required premises are acquired. No common theory from
another topic is free. There is no pooled ratio and no newly computed fraction.

The final embedded-listing audit is a separate bound input. Its positive screening
is limited to counted representations and available replacement TeX, not unseen
editions or unextracted graphics. This author reuses that audit and the published
expanded-F screen; the correction is not another scientific or source-input audit.

Run the portable check (fresh output directory required)::

  /path/to/python -B -O check.py --public-root /path/to/math_compression \
    --out /fresh/path --render --xelatex /path/to/xelatex

Omit --render to skip rebuilding the reader and current graphs; all saved data,
SVG/PDF geometry and corruption controls are still checked. Python needs pypdf and
matplotlib. XeLaTeX with STIXGeneral rebuilds the reader. No original source files,
scientific GAP computations or Lean compilation are needed. Copied baselines and
all audit exports are hash-bound; the public repository is read only.
