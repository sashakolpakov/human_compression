The current Chamber, ChiralEnumeration and Operations comparisons count embedded source programs while their replacement scientific papers contain no executable listings. We propose excluding the concrete listings on both sides. This changes a measurement boundary, not the mathematical contracts. Required algorithms, computations, witnesses, data and retained theorems remain required.

The complete boundary is six originals and eleven replacement papers: seventeen PDFs and 215 pages. Every title, proof, mathematical algorithm description, table, reference and application companion remains included under its existing furniture and glyph policy. All eleven replacement listing masks are empty. Fourteen documents are unchanged exactly.
