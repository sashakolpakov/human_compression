Five exact character-table inputs for L036
========================================

This request exports data for M11, M23, M24, J1 and Ru only. Their
nonabelian simplicity, names, orders and trivial outer automorphism groups
are explicit classical premises. The complete maximal-subgroup lists and
compatible class fusions are supplied by the installed Character Table
Library; its Maxes documentation states that contract. The table data are
borrowed premises, not new classifications proved by our consistency checks.

The exporter constructs no groups, cosets, automorphism groups or geometries.
It returns parent centralizer orders and the square-class map, followed by
one maximal table's order, centralizer orders and stored fusion per class.
An independent Python application can compute each permutation character
using formula (2) of methods.tex and then use formula (1). It must verify
all class-size sums, order divisibilities, fusion lengths and ranges,
nonnegative integral fixed-point values, subgroup indices, character orbit
counts and the final integer. The raw source totals are comparison targets
only and are not inputs to the export or arithmetic.

The previous aggregate probe remains unaccepted evidence. This export adds
the small exact input needed for independent arithmetic rather than rerunning
the previous GAP induction calculation. It does not settle outer cases,
suborbit multisets, M11 incidence graphs, designs or the entire source.

The single process has a 30-second external deadline, a 512 MiB GAP workspace
limit, an 8 MiB total-output cap, a 4 GiB prelaunch reserve and a 2 GiB emergency
floor. No successor is launched. If the reserve is absent, the runner records
a hold on stdout and launches nothing. Actual stdout/stderr and terminal
receipts are preserved without correcting or normalizing unexpected values.
The root must review this frozen request before any execution.
