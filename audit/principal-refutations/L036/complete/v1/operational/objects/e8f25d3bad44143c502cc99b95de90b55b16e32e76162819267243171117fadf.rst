The remaining M11 graphs in L036
================================

This is one finite Python computation, using the previously acquired complete
7920-element degree-eleven M11 model and the retained 39 subgroup generator
arrays. It performs no GAP call or new subgroup classification. The accepted
L054 numerical census supplies completeness and the five maximal classes
38,37,35,34,27. The retained named model and the classical Out(M11)=1
premise identify the resulting inner action with the source's equivalence.
The old six-case IP2 geometry census is neither used nor a coverage premise.

The program first checks every retained element is a permutation, the entire
model is generated by its two named generators, and each supplied subgroup
closes within it. Conjugating the five maximal representatives by the two
generators enumerates their complete conjugacy orbits. The same generator
action on unordered pairs partitions every pair of distinct maximal
subgroups. The exact partition, generator actions, actual subgroup sets and
conjugators are returned. No printed orbit count is an acceptance input.

For each pair representative H,K, the program partitions the full group
into literal right cosets of H and K. Each group element gives one edge
between its two containing cosets. Thus the retained adjacency is exactly
the source's nonempty-intersection incidence relation; every edge is counted
|H intersection K| times. The program checks that identity on actual arrays.
All vertices are visited by breadth-first search, giving every eccentricity.
The two type diameters are therefore exact, without a transitivity shortcut.

For girth, every non-tree edge in a breadth-first tree gives a closed walk
of length d(u)+d(v)+1 containing a cycle no longer than that value. The
least value over all roots is at least the true girth. Taking a root on a
shortest cycle gives a breadth-first collision of length at most that
cycle, so the minimum is the true girth. The graph is simple and bipartite;
only non-parent edges are used. The proof application will retain this
justification rather than assume one rooted BFS suffices in general.

For every graph and both orientations, block neighborhoods are retained.
For each subset size t, the program intersects bit sets of incident blocks
for every t-subset, stopping at the first two unequal counts. A uniform
level is therefore a literal design certificate, and a failed level has
two explicit witnesses. Uniformity at t+1 implies uniformity at t by double
counting, so a first failure excludes all greater nonvacuous strengths.
Complete incidence is recognized separately, with an explicit formula for
all t. Distinct block counts are retained; no simplicity convention is
silently imposed. A fixed 250000-subset cap preserves partial status if an
unexpected larger design is encountered. Actual results are never changed
to match the source's Table4 or its dual-orientation convention.

Each actual intersection is transported by an explicit ambient conjugator
to one of the acquired 39 subgroup representatives. This gives a precise
interface for importing previously accepted structural proofs. Named
intersection identifications and all source Table3/Table4 joins remain
unaccepted until the returned data and those imports are reviewed. In
particular GL2(3), Q8:S3 and the source's M8:S3 notation require an explicit
naming bridge; no abstract shape is inferred solely from its order.

Limits: one initial invocation, 60 seconds external wall time, 1 GiB Python
address-space ceiling, 16 MiB combined output, 4 GiB prelaunch reserve and
2 GiB emergency disk floor. The retained owner has the already reviewed
try/finally kill-and-wait supervision, final resource checks and final input
rehash. No successor is authorized. The acquisition returns whatever actual
finite data it obtains; the source comparison is a separate application.
There is no whole-source, new refutation, measurement or Lean credit here.
