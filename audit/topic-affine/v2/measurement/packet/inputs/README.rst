Replay
------

Use Python with pypdf 6.13.0 and fontTools 4.63.0. Place the primary PDF at its exact
path and hash under the study root. The replacement PDFs, full programs and
scope may be read from the public repository::

  python -B -O extract_inputs.py --study-root /path/to/private/study \
    --public-root /path/to/human_compression --out /fresh/output

Omit ``--public-root`` to use the bound private replacement paths. The output
must not exist, including as a symlink. The runner verifies full-document
selection, exact furniture, original font events, all complete file hashes
and the admitted thirty-three-row scope. It saves counts and hashes, never
primary PDF text, images or font bytes. It does not execute the mathematical
programs or recompile Lean, whose proof review is already separately bound.

``author_counts.json`` contains 120 PDF metric cells and 60 raw-program cells,
plus separately labeled auxiliary/formal files. The three text policies are
raw untrimmed, raw selected and calibrated selected, each in NFC and NFKC and
five length units. Eleven deliberately corrupted inputs are rejected.
``portable_replay.json`` records an independent process using only the exported
measurement metadata/scripts and the admitted public replacement bytes. This
is author replay, not independent numerical acceptance.
