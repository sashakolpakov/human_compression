Affine manuscript costs and proof dependencies
==============================================

This private author packet assigns the complete measured text of L012 and its
replacement to exclusive passage owners. It preserves the accepted affine
logical graph v2, the 33 source records and every existing complete-document
measurement. Independent ownership review is pending. The author previously
reviewed the graph and authored the canonical mathematical volume; those roles
are disclosed rather than presented as an independent cost review.

Start with reader.pdf, then historical_graph.svg and new_graph.svg. Both vector
graphs can be enlarged. They show prerequisites pointing to uses and retain
unknown external proof costs. A box's interface can share passages with other
boxes; do not add the box labels. The complete arithmetic is in weights.json.

Reproduction
------------

Use the already bound study tree; no new download, GAP census or Lean run is
needed. Its exact original PDF is required locally and is not redistributed.
The extraction uses pypdf 6.13.0 and the frozen font/glyph policy. Fonttools and
Matplotlib are the existing input/reader dependencies. Fresh output directories
are required. From research/leemans::

  /Users/sasha/.venvs/global/bin/python -B -O topic_Affine_dag_costs/check.py \
    --study-root /Users/sasha/medusa/research/leemans --out /private/tmp/affine-cost-check-new
  /Users/sasha/.venvs/global/bin/python -B -O topic_Affine_dag_costs/check_reader.py \
    --study-root /Users/sasha/medusa/research/leemans --out /private/tmp/affine-reader-check-new

The first check re-extracts the four exact PDFs, checks every input binding,
regenerates exclusive costs and closure unions, and rejects seventeen mutations.
The second regenerates both graphs and the reader source, checks every displayed
node and mathematical edge, the full-library acquisition, and eight mutations.
It is a static SVG/data check, not a browser test. To recreate the author data::

  /Users/sasha/.venvs/global/bin/python -B -O topic_Affine_dag_costs/author.py \
    --study-root /Users/sasha/medusa/research/leemans --out /private/tmp/affine-owner-new

To render the reader, run build_reader.py with the same arguments into a fresh
folder, then run XeLaTeX twice on reader.tex there. PDF byte timestamps may
change; the two extracted page texts are bound by render_report.json.

File roles
----------

protocol.json fixes the input pins and allocation rules. boundaries.py contains
semantic cuts and explicit shared-statement owners; partition.json binds their
exact codepoint spans and hashes without exporting primary text. accounting.py
projects the same partition through the three accepted extraction policies.
atomic_base.py is byte-identical to the earlier accepted allocator. The longest
matching logical ID prevents a theorem prefix from swallowing its separately
proved corollaries. ownership_notes.json explains the nontrivial interfaces.

weights.json stores exact unions and a byte-content-equivalent JSON copy of the
admitted full-document result; owner_costs.csv is the complete owner table.
input_bindings.json pins the independent arithmetic and logical acceptances.
The static graphs contain all mathematical prerequisite edges on their side;
other edge kinds remain in the bound logical graph and are not treated as
premises. Acquisition is a reading order, not research chronology or evidence
for a repeated sawtooth pattern. GKM inspection and its limited reuse lesson are
recorded in ownership_notes.json; no GKM code is a mathematical premise.

No earlier freeze or public file was edited. No source, question, formal theorem
