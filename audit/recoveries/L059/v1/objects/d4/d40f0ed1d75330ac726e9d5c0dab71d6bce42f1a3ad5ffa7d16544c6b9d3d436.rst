Actual actions for subdivision columns
======================================

The theorem proves equality with the old coset-action columns uniformly.
The finite check compares every field of ten already retained rows.
It does not rerun a graph census or claim a whole-original recovery.

Replay with pynauty not required (GAP only)::

  python check.py --sources /path/to/L059_recovery_work --replay /fresh/directory

The replay directory must not exist. The exact witness inputs are pinned
in inputs.json. Original and new libraries are both included unchanged.
