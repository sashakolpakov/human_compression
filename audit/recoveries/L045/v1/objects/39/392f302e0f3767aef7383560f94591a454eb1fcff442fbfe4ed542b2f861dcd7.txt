Counting involutions that generate a chiral polyhedron
Human Compression project
We give one counting argument for fourteen sporadic cases of the existing existence theorem
of Leemans and Liebeck [1]. It uses ordinary class sizes and a complete list of maximal subgroup
classes. Both are retained classification inputs, with their exact numerical use recorded. The
same involution bound handles all fourteen cases without distinguishing the conjugacy classes of
reversing automorphisms.

3 Inputs, verification, and attribution
The source’s existing existence conclusions are being reproved, not claimed as new. The retained
facts are the identifications of the sporadic groups and their automorphism groups, the complete
lists of maximal subgroup classes, the ordinary class sizes and element orders, and the displayed
inclusion fusions. The verifier obtains the numerical data from GAP’s Character Table Library,
in its recorded edition. ItsMaxesattribute is documented to give one representative for every
conjugacy class of maximal subgroups when it is present. Completeness of those classification
lists is a premise; it is not proved by iterating over a software list.
For every required table, the checker sums the sizes of the classes of exact order two orp.
It retains every maximal-subgroup class, including repetitions of a table name when distinct
subgroup classes have the same character table. It verifies each centralizer index used in (4), the
actual inverse-class test in (2), and all fourteen strict inequalities with exact integers or rationals.
The full underlying rows and their source bindings are retained, so the small displayed table is
not an unexplained set of trusted totals.
Together with the separately reviewed twelve explicit word certificates, these fourteen cases
cover all twenty-six sporadic groups in the source theorem. The alternating branch has its own
uniform proof. The classical and exceptional Lie families remain separate obligations.
