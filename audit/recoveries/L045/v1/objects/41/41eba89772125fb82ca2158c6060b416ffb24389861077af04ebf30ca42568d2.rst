Complete mathematical reading
-----------------------------

The generation union bound is valid for each selected element x. A maximal
subgroup of a nonabelian simple group is self-normalizing, so double counting
the conjugating elements gives exactly |C_G(x)| |x^G intersect M| / |M|
conjugates containing x. Replacing the class intersection by all elements of
order p only enlarges the count. The summation must retain separate maximal
conjugacy classes, and the actual code does so; its table-query deduplication
does not deduplicate the maximal-class summands.

For a generating pair (x,t), an automorphism inverting x and fixing t has
square fixing both generators. It is therefore an involution, since the
chosen odd order of x excludes the identity. All inverters in the full
automorphism group form one centralizer coset, or the empty set. Bounding
their union of fixed involutions by |C_A(x)| mu is valid even when many
elements of that coset are not involutions. Non-realness is checked in A,
after the actual inclusion fusion, rather than only in G.

The coarse mu lemma is sound. Aut(G) has trivial centre because an
automorphism centralizing every inner automorphism fixes each element of
the centreless group G. Consequently every involution centralizer is proper.
In the index-two case the proof needs an outer element in each centralizer
of an inner involution, and the exact fusion/centralizer equality is verified
for every such class. An outer involution supplies its own outer element.
Thus the centralizer lies in a maximal subgroup other than the socle. The
actual identified socle is the single omitted maximal class. Identification
and fullness of A are retained inputs, not conclusions inferred from order.

For the polyhedral conclusion, y=x^{-1}t generates G together with x and
has (xy)^2=1. An element in both cyclic groups commutes with both generators,
so the cyclic intersection is trivial. Orders one and two for y would make
G cyclic or dihedral, respectively. This pays the actual rank-three
intersection and nondegeneracy hypotheses before invoking the retained
reconstruction theorem. The excluded reversal has precisely the source's
(x,t) convention. No regularity or chirality inference comes from group
order alone.
