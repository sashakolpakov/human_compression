Orthogonal torus interface
==========================

Author: root. This component proves projective element orders, actual natural
conformal torus centralizers and exclusion of ordinary field reversers.
It does not cover triality, maximal overgroups or the whole L045 theorem.
Spinor norm conventions are attributed to Murray--Roney-Dougal2008.
The first control attempt failed before any case (read-only GAP global);
it is preserved under development_initial and supplies no evidence.
The final controls use local variables. No mathematical statement changed
as a consequence of that implementation failure.

The initial integrated wrapper rejected GAP's leading carriage return while
counting lines. Its stdout and initial wrapper are preserved; the correction
ignores whitespace-only lines, while still requiring byte-identical output.
