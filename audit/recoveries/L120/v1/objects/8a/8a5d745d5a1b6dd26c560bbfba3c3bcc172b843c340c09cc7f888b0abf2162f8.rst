Orbit enumeration on its actual invariant domain
================================================

At every recursive node St centralizes each selected involution. It therefore fixes the generated subgroup H setwise (indeed pointwise), and it preserves the set of involutions commuting with every earlier mark imposed by pool. Conjugation also preserves the complete involution set. Hence the candidate involutions in pool outside H form an St-invariant set. OrbitsDomain(St,candidates,OnPoints) therefore returns precisely the same orbits as Orbits with all candidates as seeds. Minimum representatives and all downstream tests are unchanged. This is an implementation change, not a pruning rule.

The current S14 attempt retains its original engine and 900-second cap. Its queue receives STOP_AFTER_CURRENT before any new attempt. A successor requires complete small-control equality and a fresh explicit plan.
