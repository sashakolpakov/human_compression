Pool intersection evaluation
============================

The current pool P is a sorted subset of the complete involution index set I.
The old next pool is P intersect {i in I: t commutes with involution i}.
It equals {i in P: t commutes with involution i}, with the same sorted order.
The new engine evaluates the latter set directly, rather than constructing
the full ambient commuting set before taking its intersection with P.
This is the sole engine change. Prefix representatives, pools, groups and
every admitted tuple are therefore identical by induction over the complete
search. No mathematical pruning or completeness scope changes.

GetCommuting remains present but unused, preserving the literal one-line
functional delta for review. Existing complete controls are the comparison
reference. Capped large attempts remain incomplete and are not certificates.
