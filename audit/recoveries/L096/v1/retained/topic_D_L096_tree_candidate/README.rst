Shadows in tree geometries
==========================

This four-page paper recovers the symmetric-group observation in L096
Section 5 by the existing all-degree tree argument. The full geometry,
residue and transfer proofs are written here; the foundational 1997
classification remains an external premise, as recalled in the available
1998 source. The unavailable L089 stays archived. No whole L096 recovery,
new original, open question, new Lean theorem or factor is claimed.

The previous project proof and distinct audit are bound in migration.json.
BooleanShadow.lean and its exact prior compilation receipt are retained:
only the Boolean witness lemma is formalized. The optional finite checker
and its completed receipt are unchanged. No old computation is rerun for
this document migration. None of these integrity checks supplies a new
mathematical review.

From this directory, with Python/pypdf and pdfLaTeX available::

  python -B check.py --out /fresh/absolute/path --render

The runner verifies exported bytes and inherited source/receipt agreement,
then optionally rebuilds all four pages and compares their extracted text.
Source full texts, old Markdown notes, fonts and raster images are not
exported. Distinct review is pending at this author freeze.
