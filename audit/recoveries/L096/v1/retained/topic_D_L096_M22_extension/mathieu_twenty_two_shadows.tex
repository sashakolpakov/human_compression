We compute every residual shadow property of the fifty previously classified
locally two-transitive $M_{22}$ geometries of ranks three through five.
The complete residue theorem in \emph{Shadows and residues in finite coset
geometries}, its sparse right-coset implementation proved in \emph{Shadows
of the Hall--Janko geometries}, and the accepted phase-seven complete
census are retained in full. This is an application of those common proofs;
no subgroup census is repeated.

\section{Actual source families and retained hypotheses}

J. Comput. Math. 7 (2004), 284--299, has 35, 22 and 9 active entries in
\texttt{m22.rk3}, \texttt{m22.rk4} and \texttt{m22.rk5}. These counts use

The check uses actual subgroup equality, not subgroup-order profiles.

\section{Complete residual decisions}
\begin{theorem}
The counts for the fifty distinct inputs are as follows. Each triple
lists IP, weak IP alone, and failure of weak IP, respectively.
\begin{center}\begin{tabular}{ccccc}\toprule
Input rank&number&$(\mathrm{IP})_3/(\mathrm{WIP})_3$&
$(\mathrm{IP})_4/(\mathrm{WIP})_4$&full IP/WIP\\\midrule
3&25&$(5,8,12)$&---&$(5,8,12)$\\
4&16&$(5,4,7)$&$(3,1,12)$&$(3,1,12)$\\
5&9&$(0,1,8)$&$(0,1,8)$&$(0,1,8)$\\\bottomrule
\end{tabular}\end{center}
For rank-five inputs the $(\mathrm{IP})_5/(\mathrm{WIP})_5$ triple is also
$(0,1,8)$. All fifty geometries satisfy $(\mathrm{IP})_2$.
\end{theorem}
\begin{proof}
For every proper set $J$ of fixed types, take the actual stabilizer
$H_J$ and the remaining parabolics $H_J\cap H_i$. The already established
flag transitivity identifies every residue of this type with this base
residue. For each target type, the common theorem reduces the required
object--flag comparisons to its complete double-coset and witness search.
We use exactly the sparse Hall--Janko algorithm: nonempty shadows are
sets of canonical right-coset representatives, and the empty flag is the
whole universe, handled by its proved cardinality test. The mathematical
program is unchanged; only the descriptive retained-census field names
the $M_{22}$ premise. Trivial panel stabilizers remain allowed.

The run covers 694 base residues including panels. The 510 base residues
of rank at least two give 1348 directional truth values. Every negative
value includes an actual normalizing permutation and failed intersection
after the complete witness search. For each rank $k$, conjunction over
all target types and all base residues gives $(\mathrm{IP})_k$; choosing a
successful type separately for each residue gives $(\mathrm{WIP})_k$.
The actual number of residues represented by a base flag is $[G:H_J]$.
Full IP and weak IP are the respective conjunctions over ranks two through
the input rank. Panels are automatic for these properties and rank zero
is excluded. Applying these quantifiers to the complete saved decisions
gives the table.
\end{proof}
