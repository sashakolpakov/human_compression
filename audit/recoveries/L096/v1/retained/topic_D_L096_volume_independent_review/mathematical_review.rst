------------------------------------

The unpruned complete algorithm does not rely on these optimizations.

transitivity transports it to all flags of that type. Weak intersection
requires an existential type separately inside each residue, followed by

one globally successful type. Panels are automatic for the shadow

represented by its whole-universe cardinality, not by a fictitious empty
