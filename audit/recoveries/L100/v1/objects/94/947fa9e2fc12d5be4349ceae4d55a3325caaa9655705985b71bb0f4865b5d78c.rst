Restricted transform and proof
------------------------------

Let w=4094. The admitted payload domain is nonempty ASCII JSON object text on a
single line, containing no backslash character. Define F by dividing the payload
into successive blocks of length w (the last block may be shorter), joining
these blocks by one backslash followed by LF. The inverse D accepts only lines
whose nonfinal lengths are w+1 with a final backslash, with a nonempty final line
of length at most w. It deletes precisely that last backslash and the following
LF at each boundary. It then requires F(D(raw))=raw, no backslash anywhere in the
payload, and strict JSON parsing with duplicate keys and nonfinite constants
rejected. By fixed block positions, D(F(payload))=payload. In particular no
backslash within a JSON escape is guessed to be a continuation.
