Every later mark fixes the literal point a. Consequently a distant mark both
centralizes P_k and fixes a, so it fixes a^(P_k) pointwise. This elementary
centralizer inference needs no alternating kernel. If growth stopped at k, the
prefix through k would preserve the preceding orbit and every later mark would
fix it. Ambient transitivity would force that orbit to be all of Omega, while
P_(k-1) is contained in the intransitive omission G_k. That contradiction also
works at k=r-1. Transitivity forces the initial moved pair, so all the stated
size inequalities follow.

At a later unique cut j, the suffix fixes C_(j-1) pointwise and the prefix is
transitive there, making it exactly the omission orbit of a. A single crossing
edge can connect all omission orbits only when there are exactly two. The suffix
therefore cannot have a shared label. This argument uses the actual ambient
omission, not a restriction with an assumed intersection property.
