A connected tree on the l-pairs
------------------------------
Let J be both contracted h-edges. Its graph rank is2. Adjoin one actual
eligible selected edge for every c in C. Each such edge is a bridge in
this graph: an alternate path would use h and other C labels but not
its own, and lifts with l to an H_c path contradicting eligibility.
There are m-3 selected C edges, so the graph rank is m-1. It is a
connected TREE T on m vertices, with h occurring twice and each C
label once. This is root's bridge idea specialized to one neighbour.

Every additional actual C edge lies within the set Y of l-pairs touched
by h. Indeed its T-path can contain only its own selected C edge and
h-edges; any other selected C label would be bypassed. If that path
contains its selected C edge, the matching property makes its first
and last edges both h, hence the path is h,c,h. Otherwise it uses only
h edges. In either case both endpoints belong to Y. This applies also
to a C edge parallel to an h-edge. Internal l-pair flips are not edges
of this simple contracted graph and are controlled by the character.

Every C mark except the possible neighbour c of h centralizes both
l,h. Their actual joint orbits meeting Y have size4 or6, whereas all
other orbits have size2. Hence those C marks preserve Y and cannot
have a selected edge exiting it. Transitivity makes some selected C
edge exit Y. Thus c exists and exactly one selected edge exits Y,
labelled c. No actual extra C edge exits Y by the previous paragraph.

Disjoint h-edges are impossible
-------------------------------
Here Y has4 vertices, in two h-edge components. Since there is exactly
one edge exiting Y, their connection in T must lie inside Y. It is one
selected C edge g; the three inside edges form h,g,h. The label g is
not c, which labels the exit. Since g centralizes l,h, its action swaps
the two four-point joint orbits, forcing the parallel second g-edge:
on Y its projected involution moves every vertex. Therefore g fails
to commute with c, since c alone takes one Y vertex outside while g
preserves Y and moves that vertex. The outside tree contains at least
4 vertices (m>=8), so an edge d is incident with c's outside endpoint.
Its projected transposition also fails to commute with c. The three
labels h,g,d are distinct noncommuting neighbours of c, impossible
for a string. This eliminates disjoint h-edges.

The h-path and its central reflection
------------------------------------

C mark can be written diag(pi)*l^chi, because it centralizes l and
preserves or swaps the binary rows. The projection of <C> on m indices
is faithful: its kernel is contained in <l>, and IP excludes l from
<C>. Thus chi is an actual character of its projected group.

Every C mark g other than c centralizes the six-point alternating path

the former chi(g)=0. The unique selected c-edge joins some y in Y to an
outside vertex x. The outside selected tree is connected.

If y=u is the middle vertex, let z'=(l h)^3. This is a fixed-point-free
central involution of <l,h>, equal to l outside Y. On Y it pairs a0
with b1, a1 with b0 and u0 with u1. It swaps the binary rows. All other
C marks commute with z'. The projection of c is (u x), optionally
multiplied by (a b); these are its only possible extra edges, by the
matching condition. Either form, with either character, also commutes
with z'. Thus all H centralizes z' and preserves its alternative pairs.

This pair system is maximal by the following actual lemma. If a
transitive H preserves the binary partition and contains a central

maximal omission H_j is intransitive. If all projected generators are

The extra (b u) gives an explicit local IP contradiction
-------------------------------------------------------
Let barc=diag((a x)(b u)), d=diag((x y)). All labels l,h,c,d are
consecutive in their connected noncommutation path, but only the
actual subset intersection property is used here. Write c0,c1 for
the restrictions of barc to binary row0,row1.

If c=barc, A=<l,h,c> contains c0: v=(h c)^2 is the pure row0 double
transposition (a u)(b x), and v^(l h l) is the different double
transposition (a b)(u x); their product is c0. Thus c1=c*c0 lies in A.
In B=<h,c,d>, e=(c d)^3=diag(b u), and h*e is a pure row0 three-cycle
on {a,b,u}. It and its c-conjugate generate A4 on {a,b,u,x}: they are
transitive on4 letters and their group order is divisible by4 and3,
so it is all A4. Thus c0 and c1 belong to B too. But <h,c> is dihedral
of order8, with faithful restriction to row0 (there h0,c0 generate
D8), so it cannot contain nonidentity c1 supported only on row1.
This violates A intersect B=<h,c>.

If c=barc*l, then e=(c d)^3=diag(b u)*l. Put q=(h e)^2. This is the
diagonal copy of the same three-cycle on {a,b,u}. It and q^c generate
diagonal A4 on {a,b,u,x}. Adjoining d, a transposition attaching y,
generates diagonal S5 on those five indices (conjugate d by the
transitive A4 to get every star transposition). Hence B=<h,c,d>
contains barc. It therefore contains l=barc*c, contrary to IP with
the disjoint singleton mark l. These are uniform word/group arguments,
not conclusions based on the diagnostic enumeration.

Endpoint centralizers of the canonical case
--------------------------------------------
The only remaining H has l the full flip, h=(a0 u0)(u1 b1), and
C the doubled Coxeter path generating S_O, where O consists of a
and all m-3 outside indices. The complete noncommutation graph of H
is the path l,h,c,d,..., so the omitted i is an endpoint of the full
parent string. There are two orientations.

If the omitted sigma is before l, it centralizes J=<h,C>. The actual
J-orbits have sizes m-1,m-2,2,1: O0 plus u0, O1, {u1,b1}, and {b0}.
They are distinct for m>=8. The induced groups on the first two are
S_(m-1),S_(m-2), so their natural centralizers are trivial. Therefore
sigma is identity on them and on the singleton; it can only flip
{u1,b1}, an odd transposition. No nonidentity even sigma exists.

If the omitted sigma is after the last tail mark, it centralizes
K=<l,h,all C except last>. There is one isolated l-pair at that last
index t and one transitive K-orbit of size2(m-1). On that big orbit,
C' is diagonal S_(m-3) on O'=O\{t}. Conjugates of h by C' give
h_x=(x0 u0)(u1 b1) for every x in O'. Products h_x h_y generate
pure A_(m-2) on O'0 plus u0. A permutation centralizing K must
preserve this alternating support and centralize its natural action,
so it fixes a point there. Since K is transitive on the big orbit,
its centralizer is semiregular and sigma is identity on that whole
orbit. It can only flip the isolated l-pair, again odd. This excludes
the canonical case.
