Rank contraction and its source applications
===========================================

This is an author packet for independent mathematical review of L037,
Brooksbank--Leemans, ``Rank reduction of string C-group representations``,
arXiv:1812.01055v2 (3 May 2019). It does not itself admit a new source,
resolve Conjecture 5.1, or establish a compression factor.

Read ``umbrella.tex`` and ``rank_spectra.tex`` in full, then ``scope.json``.
The common paper proves the forward central twist, the elementary dihedral
obstruction, the contraction induction, the exact parity test for recovery,
and the iteration. The application discharges the principal source theorem
and rank-interval consequences, preserving the stated classical construction
inputs. The whole one-page ``programs.pdf`` prints the complete GAP program
for the source's finite matrix example and all three literal A11 diagrams.

The scientific edition has 3 common pages, 5 application pages, and 1 code
page. All are part of this packet; no existing Topic B common paper is a
free premise. The standard end criterion and the explicitly named classical
seeds are retained external mathematical inputs. The odd-characteristic
Monson--Schulte III primary is not locally acquired: its precise seed is
retained through the source's Section 4. The independent reviewer should
specifically assess that declared boundary. The original paper's printed
Corollary 1.3 has the indexing qualification recorded in application Section 1.
Its Conjecture 5.1 remains open in this packet.

``--gap``, ``--lean``, ``--packages`` and ``--xelatex`` can specify equivalent
installed tools. The checker binds source and older audit bytes but does not
redistribute primary PDFs. It executes the complete finite examples, rejects
four damaged programs, compiles four actual algebraic Lean declarations,
rejects three weakened hypotheses, and rebuilds all PDFs twice with exact
per-page extracted-text and complete program-inclusion checks. The Lean
source has explicit root handling, so export-only replay does not depend on
the process working directory. Cached pinned Mathlib objects are trusted.

The four Lean statements are algebraic interfaces, not a formalization of
string C-groups, the full contraction proof, the retained classical seeds or
the finite GAP computations. GAP is trusted for the finite certificates.
The uniform written theorem does not depend on finite sampling. The source
rows distinguish proved deductions, retained facts, the indexing qualification,
and the unsolved conjecture. The 22 rows are not 22 manuscripts.
