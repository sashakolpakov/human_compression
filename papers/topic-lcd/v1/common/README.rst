Incidence operators, orthogonal codes and permutation modules
============================================================

A complete fourteen-page common manuscript, assembled from six already
reviewed proof fragments with shared finite module/group criteria and a
full classical MacWilliams proof. This packet is awaiting distinct review.
It grants no complete-source recovery or compression credit.

Compile umbrella.tex twice with pdflatex. The document has no external
TeX inputs. interface_labels.json gives the stable application interfaces;
migration.json records the exact inherited fragments and destinations.
assemble.py is an author workflow, requiring the named private predecessor
packets. It is not needed to read or build the complete umbrella.tex.
Required mathematical computations remain those explicitly declared in
bindings.json and the application contracts. No large enumeration is run
by assembly or document compilation. Frozen predecessor packets are unchanged.
