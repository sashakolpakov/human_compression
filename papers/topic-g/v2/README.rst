Reproduction
------------

With GAP and its required packages, the pinned Lean package tree, Python with
pypdf, and XeLaTeX with the stated fonts installed, run from this directory::

  python -B -O check.py --out /fresh/absolute/path --render \
    --study-root /path/to/private/study

The study root is optional: it only checks the four already acquired primary
PDFs against their hashes, and no source is downloaded. Tool paths can be set
with ``--gap``, ``--lean``, ``--packages`` and ``--xelatex``. For export and source
bindings alone use ``--bindings-only``. The output directory must not exist.
The driver removes inherited Python optimization for unchanged legacy children,
uses explicit fail-closed checks itself, regenerates the Witt Lean input and
rejects eight mathematical mutations. ``render.py --help`` describes the
separate whole-code inclusion and PDF text check.
