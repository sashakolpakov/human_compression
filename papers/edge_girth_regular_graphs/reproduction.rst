such as ``/tmp`` when ``/private/tmp`` is its canonical location. The output

    "$F012_PYTHON" -E -B "$F012_ROOT/scripts/edge_girth_regular_graphs/execution/environment.py" \
      --root "$F012_ROOT" --plan-sha256 "$PLAN_SHA" \
      --compiler "$F012_COMPILER" --nauty-prefix "$F012_NAUTY_PREFIX" \
      --python-site "$F012_PYTHON_SITE" --out "$F012_ENVIRONMENT"

four installed distributions through metadata, discovers exact module/header/

serves both Atlas 9 fields; ``python.networkx.module`` serves both Atlas 22
fields. Old author host paths are not public configuration keys. No one needs
to hand-fill 32 path/hash entries.

The generator reads metadata and selected bytes only: it does not install

One bounded application
-----------------------

The following commands invoke the package interface. A command listing is
not a record of execution or approval. Obtain ``PLAN_SHA`` and ``F012_ENVIRONMENT_SHA``
from the reviewed package/environment handoff, choose a declared ``ROUTE``
from ``route_index.json``, and use a fresh ``WORK`` outside the package tree.

``order51_modular_order51_modular`` is the separate complete modular route.

    "$F012_PYTHON" -E -B "$F012_ROOT/scripts/edge_girth_regular_graphs/execution/execute.py" \
      --prepare --root "$F012_ROOT" --plan-sha256 "$PLAN_SHA" \
      --environment "$F012_ENVIRONMENT" --environment-sha256 "$F012_ENVIRONMENT_SHA" \
      --route "$ROUTE" --work "$WORK"

This creates fresh case/config/request metadata and returns its exact request
pin. It does not import the acquired worker, materialize mathematical payloads
or run science. The plan permits only explicitly named package/environment
field changes; complete original reports, controls and numerical expectations
remain intact. The whole inverse is checked.

    "$F012_PYTHON" -E -B "$F012_ROOT/scripts/edge_girth_regular_graphs/execution/execute.py" \

Its initial resource observations are not a reservation against unrelated
