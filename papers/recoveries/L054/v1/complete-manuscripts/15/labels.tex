\paragraph{Proof of the finite application.}
The literal verifier closes every listed permutation group. New model
references are acyclic. In each split model it checks the actual normal
subgroup $N$, its already verified structural description, a subgroup $K$
with the displayed complement description, $N\cap K=1$, and
$|N||K|=|H|$. The product is all of $H$. A noncommuting generator pair
certifies the displayed nontrivial semidirect action. Normality and
commutation tests on generators extend to the whole generated groups.

There are twenty new split and two new nonsplit models. The latter use
the already proved composite-quotient lift criterion: for cyclic quotient
of order six, fixed generator $xN$ lifts to a complement exactly when
some $a\in Nx$ has $a^6=1$; for quotient $S_3$ with fixed generators
$xN,yN$, a complement exists exactly when some lifts satisfy
$a^2=b^3=(ab)^2=1$. The checker first verifies the actual quotient
relations and six cosets, then tests every required lift or lift pair.
The $Q_8\mathbin{\cdot}6$ model uses eight lift checks, and the
$(D_8:2)\mathbin{\cdot}S_3$ model uses 256 pairs. Their failure of the
splitting relations proves nonsplitting, independently of any unsuccessful
complement search.

Every source occurrence is transported to its exact embedded group
under the acquired numerical row map. The source text, native syntax tree,
order, subgroup index and generator arrays all agree. There are 307
checked transports and 146,010 right-generator edges. These checks prove
the stated finite result, using only the explicit acquired interfaces.
