# Current work and available proofs

The active task is to turn the existing reviewed manuscripts into
**topic umbrellas and families of complete application papers**. See the
[programme](MANUSCRIPT_PROGRAM.md), [complexity protocol](TOPIC_COMPLEXITY.md)
and [dependency pilot](DEPENDENCY_PILOT.md). The existing combined A–D manuscripts
are material for that task, not completed Aᵢ/Bᵢ families.

The first completed pair is [Topic A’s umbrella and L032 application](TOPIC_A.md),
with independent review, complete 15+4-page texts and 34 inherited Lean checks.
This reorganizes an existing recovery and adds no principal-source credit.

## Further application material

Each page states exactly which source results it recovers. Listing it here
does not claim that an entire paper has been recovered or that the new
families of application papers are complete.

- [Parallel gluing](PARALLEL_GLUING.md): a criterion for one direction action
  to lift in every factor, and a correction to the pairwise criterion;
  part of the source paper has been recovered.
- [Finite incidence representations](FINITE_INCIDENCE_REPRESENTATIONS.md):
  derivation of the main constructive theorems with explicit local corrections.
- [Graph incidences](GRAPH_INCIDENCE.md): Livingstone constructions and
  a repaired incidence condition; part of the source paper has been recovered.
- [Design residues](DESIGN_RESIDUES.md): the corrected rank-three results,
  higher-rank Steiner classification and rank-six Mathieu construction;
  borrowed classifications and missing named-residue identifications are explicit.
- [Large cyclic subgroups](LARGE_CYCLIC_SUBGROUPS.md): high-exponent
  classification application with the source's wider catalogue excluded.

The [source registry](PAPER_MAP.md) records the papers studied, which
texts were obtained and which results were recovered. These categories
overlap; none counts completed new topic papers. Work on open questions
has its own [results catalogue](CONJECTURE_RESULTS.md).
