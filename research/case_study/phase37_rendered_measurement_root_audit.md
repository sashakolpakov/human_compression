# Root review of the rendering-sensitivity experiment

10 October 2026. PASS for the bound measurement and fresh replay, not for a
final compression factor or an expanded source-coverage claim.

I read the entire runner and protocol. They verify the frozen body helper,
source files, source/exclusion spans and exact two-paper replacement body.
The runner uses the same counting function for every representation and
normalization. No mathematical text is repaired or dropped to improve the
ratio. The only special rendering definition maps the proof-end character
to a mathematical black square. Sources are read but not copied to outputs.

I independently ran the frozen tool in a new scratch directory using the
available Python environment with pypdf6.13.0. The initial default Python
lacked pypdf and stopped before creating that directory; selecting the
installed environment resolved the dependency without changing the tool.
The fresh run matches every source/body count, raw replacement count,
rendered NFC/NFKC count, AST hash and extracted-text hash of the author run.
It has nine pages, 362 inline and19display math expressions, all21proof-end
squares and empty rendering stderr. The source and frozen artifact hashes
were checked before export. PDF bytes themselves are not claimed stable.

The prior root visual inspection covered rendered pages2and3, including
subgroup formulas, cuts, equation tags and a cases display. This limited
inspection is disclosed; the automated replay is not a full visual or
mathematical audit of every extracted glyph.

This experiment shows that rendering the replacement changes the numerical
comparison. Under NFC, the descriptive source/rendered quotients are
1.210121 for whitespace tokens,1.243398 for alphanumeric units and1.059536
for nonwhitespace characters. These are reproducible measurements of the
bound representations. N001 still has damaged browser text and no original
PDF, while N003 and the replacement have PDF-derived glyphs. Source and
replacement layouts also differ. Accordingly no robust scalar factor,
third-paper numerator or three-paper measurement is approved here.
