# L003 formal-certificate build provenance

The two theorem sources are original work. The generic module proves the presented-group infinitude criterion; the literal module supplies all finite hypotheses and derives `Infinite P6`. The written source-identification review and independent integer-array replay are separate artifacts.

The final portable runner checks the Lean version against `formal/dependency_manifest.json`, checks every listed package's Git revision and tracked-file cleanliness, and uses only those package libraries. An inherited `LEAN_PATH` is replaced. Existing compiled package objects remain trusted dependency inputs, as in the project's other Lean builds; this is not a rebuild of all mathlib.

The installed checkout lacked compiled objects for `Mathlib.GroupTheory.Coprod.Basic` and `Mathlib.GroupTheory.PresentedGroup`. Their pinned sources are compiled in a fresh output overlay. The overlay initially links the existing mathlib library, and replaces only required directories with local directories containing links to their unchanged siblings. No dependency checkout is modified. The report records both newly compiled source hashes; no third-party source text or compiled object is included in the export manifest.

The saved final reports come from a fresh run of the final runner and bind the executed theorem bytes. Earlier interactive prototypes included missing-dependency and incomplete-proof errors; their failure reports were overwritten during development and are not represented as preserved evidence. The first successful build predated the runner's explicit Git checks. That executed runner and its report are retained privately under `phase32_discovery/`, with their original hashes, outside the export allowlist. The theorem sources did not change between the first successful build and the final pinned build.

The final reproduction command is documented in the literal module's scope file. It requires Python's standard library, Git, Lean 4.32.2, and the already built pinned package checkout. GAP and SymPy are not used by either the finite transcription replay or the formal build. The source-paper identification and the extension from six to its positive multiples remain written proofs, not formal claims of these modules.
