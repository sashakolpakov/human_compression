# Clarification of the fixed measurement protocol

10 October 2026, after the first measurement. The premeasurement protocol
is preserved unchanged. Its sentence “Historical finite programs were used”
states more than the inspected primary evidence establishes. L083, physical
page 9, describes a computation using a package such as Magma, with a hand
calculation also possible. That passage does not establish the existence or
use of a particular historical program.

The accurate statement is: a historical supporting program, if any, is
unavailable here; its artifact cost is unknown. No particular positive cost
is attributed to it. The lower-bound calculation remains valid because any
such cost is nonnegative. The written comparison and every bound interval,
normalization, metric, and denominator remain unchanged.

The calculations measure the specified principal proofs relative to their
listed external inputs. The later PGL2 source already uses the earlier PSL2
table. It is charged only for the text it actually prints, not a second
copy of that table or an invented second program.
