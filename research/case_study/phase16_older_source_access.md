# Older primary sources recovered in phase sixteen

Private access record, 10 October 2026. These are reading-depth statements, not additional theorem counts. No frozen inventory or public artifact was changed.

## Archer–Cara–Krempa 2005

The complete nine-page paper *Using the Frattini Subgroup and Independent Generating Sets to Study RWPRI Geometries*, Beiträge zur Algebra und Geometrie 46(1),169–177, was retrieved from both <https://ftp.gwdg.de/pub/EMIS/journals/BAG/vol.46/no.1/b46h1car.pdf> and <https://emis.muni.cz/journals/BAG/vol.46/no.1/b46h1car.pdf>. Both return identical 181,798-byte PDFs, SHA-256 `cfbd53bc367ecaea644214eb0f64fc5db0c20d63096fdc239cf5d61c3f72c5c9` (the machine-readable intake supplies the authoritative full digest). The validated private copy is `sources/phase16_frattini_geometries.pdf`, and `sources/phase16_frattini_geometries.txt` is its complete pypdf extraction with physical/printed page markers. All statements and proofs were read. The reduction and its limits are in `phase16_frattini_geometry_reduction.md`.

The principal EMIS hostname redirected to an unrelated serial landing page. A guessed Heldermann URL returned HTML. Neither response was counted as a PDF. The ResearchGate author-uploaded rendered text was useful for discovery, but the final reading and source binding use the complete PDF.

## N001: Buekenhout–Cara 1998

*Some properties of inductively minimal geometries*, Bulletin of the Belgian Mathematical Society 5,213–219, DOI [10.36045/bbms/1103409005](https://doi.org/10.36045/bbms/1103409005).

The [Academia entry](https://www.academia.edu/54639280/Some_properties_of_inductively_minimal_geometries), reached through Philippe Cara's publication profile, exposes the complete authored paper as browser-readable text. The main text was read from the title through the references. It includes the previously missing proof of Lemma 5 and the remaining arguments on printed pages 217–218. The private retrieval record is `sources/phase16_N001_browser_record.txt`; the authored body occupies the displayed lines 181–220. The text contains all definitions, Lemmas 1–7, Corollaries 1–2, Theorem 1 and their proofs.

This improves access from partial to complete rendered primary text. It is **not** a newly acquired original PDF, and the record also contains website navigation and unrelated recommendation text outside the identified body. Direct curl returned a challenge page. A future measurement must specify the exact rendered-text extraction and cannot silently treat its character offsets as offsets in an original-PDF extraction. The four principal results had already been rederived; finding the missing text is not another mathematical result.

## Sources still incomplete or misidentified

- **N002**, Cara–Lehman–Pasechnik 2001, *On the number of inductively minimal geometries*: CiteSeer links redirected to unavailable archive captures; the NTU repository required an unavailable page; Elsevier's API returned an authorization error. Primary search excerpts include the last-page discussion but are not a complete verified source. An Academia metadata entry displays an unrelated abstract and is not treated as verified full text.
- **N004**, Cara 2003, *Truncations of inductively minimal geometries*: the Academia entry could not be opened and Elsevier's API returned an authorization error. No new complete primary text was acquired.
- **L085**, Leemans 2006, *Almost simple groups of Suzuki type acting on polytopes*: the AMS source remained inaccessible. The Luxembourg-hosted file `szpoly3 révisé.pdf`, sometimes linked beside L085, is actually the complete **L074** Kiefer–Leemans counting paper, not the three-page 2006 paper. Its valid PDF response is preserved privately as `sources/phase16_L085_author.response`, but does not upgrade L085 access. L085's principal rank/existence theorem remains available through L074's explicit restatement, as already recorded.

The complete 2005 source is therefore the strongest new principal-result target in this retrieval pass. A shared N001/N003 proof measurement can now be considered separately, with the representation difference disclosed; no new ratio is asserted here.
